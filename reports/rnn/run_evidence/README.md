# 유재윤 RNN 실행 증빙

R01~R03의 9회 RNN 실행과 M01·C01·L01의 9회 비교용 재실행을 보관한다. 각 폴더의 config·history·metrics·validation_predictions·split·metadata·복원 기록과 학습 로그는 원본 바이트다. model.keras·initial_weights.npz·preprocess.npz와 데이터는 jaeyoon-rnn-v1-full.zip Release 자산에 보관한다.

여기 C01은 14,054개 파라미터의 계획서 CNN이다. 현재 main의 최승빈 CNN C01(85,574개 파라미터)과 구분한다. 결과·실행 ID는 원본대로 유지하며 다른 담당자의 공식 결과로 기재하지 않는다. 정확한 당시 코드는 ../frozen_source/다.
