# 실행 기록과 이번 게시 소스의 관계

9회 RNN 모델·초기 가중치·학습 곡선·예측·메타데이터를 원본 그대로 선별했다. 메타데이터의 당시 전체 개발 코드 해시는 `8b3c4c3d0a2eee0c9bd609c412ba02bbe71b2412a7859fd3d1fbda78a2274a51`이다. 이 해시는 당시 공통 개발 폴더의 전체 소스·설정·스크립트에서 계산됐으며 RNN 전용 게시 폴더의 해시를 뜻하지 않는다.

이번 게시본은 RNN 모델·수식 검증 코드를 유지하고, 최신 팀 main에 RNN 전용 학습 진입점을 추가했다. 분석·그림·설명은 RNN 9회와 한글 표기로 정리했다. 과거 전체 개발 폴더를 그대로 게시한 소스 스냅샷은 포함하지 않는다. Release 파일별 SHA-256은 RNN_RELEASE_MANIFEST.json에 별도로 기록했다.

저장 예측의 지표를 재계산하고, 저장 모델을 검증 1,775개 전체에서 새 프로세스로 재로딩한 기록을 제공한다. 현재 코드로 새로 학습하면 코드 해시와 실행 환경이 달라질 수 있으므로 과거 수치를 새 학습 결과로 바꾸어 기록하지 않는다. 코드·데이터 파일 해시와 테스트·노트북 실행 기록은 함께 보관한다.
