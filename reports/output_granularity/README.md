# 기존 예측의 출력 수준별 개발 분석

2026-10-15. [활용 시나리오·해석·실제 예시 그림](../../docs/application-evidence-20261015/README.md).

- `analysis.json`: 고정 매핑·한계·18개 입력 예측 해시·54개 전체 혼동행렬·요약.
- `summary.csv`: 여섯 조건 × 세 출력 수준의 seed 평균·표본 SD 및 최저 사람 평균.
- `runs.csv`: 개별 seed별 전체 지표. `fine_errors`는 원래 6종 오류이며 `within_group_fine_errors`는 더 큰 묶음 안의 혼동이다.
- `subject_metrics.csv`: 개별 seed·사람·출력 수준별 지표.
- `l02_error_examples.csv`: L02 세 실행의 6종 오분류를 모두 보존하고 3상태에서도 틀리는지 표시한다.

6종은 원래 라벨, 3상태는 이동 / 앉거나 서 있음 / 누워 있음, 2상태는 이동 / 정적 자세다. 정답과 저장된 6종 argmax 출력에 같은 매핑을 적용했다. 다른 과제로 바뀐 점수를 원래 6종 성능 향상으로 해석하지 않는다. 이 표는 기존 행동군별 평균 F1(`reports/team_error_analysis/behavior_group_summary.csv`)과 정의가 다르다. 그 파일은 6종 F1 세 개의 평균이며 이 분석은 라벨을 묶은 혼동행렬에서 지표를 새로 계산한다.

모든 실행은 동일한 개발 사람 분할이다. 새로운 모델 실행·재학습·test 평가는 없으며, 반복 seed는 독립적인 추가 사람 표본이 아니다. 기존 기준 구성과 대표 결과는 유지한다. 사후 분석이므로 고정 출력 정책과 새로운 사용자 평가, 단순 기준 모델 비교가 뒤따라야 실용성을 더 강하게 주장할 수 있다.
