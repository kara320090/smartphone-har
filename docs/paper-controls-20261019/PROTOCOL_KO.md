# 원고 v9 보완 분석: 실행 전 고정 규약

2026-10-19 · v8의 신경망 결과·3상태 매핑을 이미 본 뒤 설계한 보완 분석이다. 아래 두 선형 모델의 결과를 확인하기 전에 기록한다. 독립 사전등록 연구가 아니다.

## 확인할 질문

1. 3상태 요약에 복잡한 신경망이 필요한가? 채널별 평균·표준편차와 선형 분류기로 어느 수준까지 가능한지 비교한다.
2. 기존 3상태의 높은 점수는 아무 3분할에서도 얻는가? 6개 라벨을 크기 3·2·1인 세 집합으로 나누는 모든 60개 매핑에서 기존 예측을 재집계한다.

## 추가 학습 2회

- 기존 fit 16명·5,577구간, validation 5명·1,775구간과 동일 ID·순서를 사용한다. 공식 test 배열은 로딩·평가하지 않는다.
- 기존 팀 표준화로 처리한 128×9 시계열에서 채널별 시간축 평균 9개·모표준편차(ddof=0) 9개, 총 18개 특징을 float64로 계산한다. 시간 순서는 사용하지 않는다.
- 특징 표준화는 fit 특징만으로 StandardScaler를 학습하고 validation에 적용한다. 기존 팀 시계열 통계의 재추정·덮어쓰기는 하지 않는다.
- LR6: 6종 정답으로 다항 로지스틱 회귀를 학습하고 6종과 기존 3상태 매핑 결과를 모두 보고한다.
- LR3: 같은 18개 특징으로 3상태 정답을 직접 학습한다. 6종 결과는 해당 없음으로 보고한다.
- 공통: L2, C=1, lbfgs, max_iter=2000, tol=1e-8, fit_intercept=True, class_weight=None, CPU 스레드 4. 특징·C·임계값 탐색은 하지 않는다. 수렴 경고가 있으면 기록하고 성공으로 처리하지 않는다.
- lbfgs는 random_state가 동작하지 않는 결정론적 최적화이므로 각 조건 한 번만 학습한다. 세 seed를 반복한 것처럼 SD=0을 쓰지 않는다.
- 분류기 계수·절편 수(6×19=114, 3×19=57)를 기록한다. 특징 추출 비용과 표준화 상수는 이 수에 포함되지 않으므로 신경망 대비 실제 속도·전력 감소로 주장하지 않는다.
- 전체·사람별 Macro F1, Accuracy, confusion matrix, class metrics, 예측 CSV, 학습 시간·수렴 횟수·모델 계수를 저장한다. 저장 계수를 새 프로세스에서 읽어 전체 validation 확률·클래스를 재계산한다.

## 매핑 대조

- 기존 네 기준 신경망(M01·C01·R01·L01) 세 seed의 저장 6종 argmax를 그대로 사용한다. 신경망을 재학습하지 않는다.
- 모든 크기 3·2·1 매핑을 빠짐없이 열거한다. 단일 클래스 집합과 두 클래스 집합을 고르면 나머지는 세 클래스 집합이므로 6×10=60개다.
- 각 매핑에서 정답·예측을 함께 변환하고 Macro F1과 상태 간 오류를 재계산한다. 기존 이동/앉거나 서 있음/누워 있음 매핑의 위치와 전체 분포를 보고한다.
- 가장 높은 매핑으로 기존 의미 기반 매핑을 교체하지 않는다. 이 탐색 순위를 유의확률·독립 검정·사전 정의된 최적성으로 해석하지 않는다. 라벨 묶음 크기는 같아도 표본 수·난도·의미는 달라진다.

## 보존·보고

기존 공동 비교 결과와 LSTM 9회 학습은 보존한다. 추가 선형 기준선이 더 좋거나 차이가 작아도 그대로 보고한다. v9에서는 새 학습이 없다고 쓰지 않고 **추가 선형 모델 2회와 기존 신경망 저장 예측의 사후 분석**으로 구분한다.

규약 변경이 필요하면 결과를 덮어쓰지 않고 사유와 별도 실행 폴더를 남긴다. 학회 투고·공식 test 평가는 이 작업에 포함하지 않는다.
