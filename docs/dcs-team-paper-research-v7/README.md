# DCS 대학생 공동 논문 v7 · 다른 대학의 두 쪽 원고 비교 반영

서울여대 2편·중앙대 1편·인하대 1편의 두 쪽 논문 전체 8쪽을 확인하고 배경·지표 설명·결과 해석·활용·결론을 보강했다. 모델 구조도와 비교표, 피험자 진단 그림을 연속 2단 본문에 배치했다. 공식 양식의 두 쪽·여백·본문 10pt와 참고문헌 두 개를 유지한다.

저자는 **이봉헌·유재윤·정회서·한윤섭·최승빈**, 제1저자·발표자는 이봉헌, 지도교수는 황세웅이다. 제목과 기존 대표 결과를 유지했다.

대표 결과는 개발 검증 5명·1,775구간, M01·C01·R01·L01의 세 seed다. 공식 test는 미평가이며 새 학습·대표 모델 교체는 없다. ±는 seed 표본 SD이며 사용자 신뢰구간이 아니다. 제외 진단은 저장 예측의 사후 집계로 인과 효과·성능 개선·LOSO 재학습을 뜻하지 않는다.

사사 적용·최종 문구, 교신저자와 최종 투고 내용은 확인이 필요하다. 공개 원고의 사사는 확인 후 기재 예정이다. 학교 지원 서류·학번·전화번호·동의서와 다른 사람의 논문 전문·그림은 공개 묶음에 포함하지 않았다. 사사 확인용 학교 별첨은 로컬에 보관한다.

그림은 `tools/make_research_figure.py --paper-layout compact`로 생성한다. v6의 큰 세 패널 그림은 보충 자료로 남겼다. [앞선 v6](../dcs-team-paper-research-v6/README.md)와 기존 보고서·수업 PPT는 수행 기록으로 보존한다. 이 자료는 제출·채택·수상을 완료한 원고가 아니다.
