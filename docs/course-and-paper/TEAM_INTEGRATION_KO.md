# 팀 공동 논문 취합과 학술 발표 준비

이 문서는 교수님의 수업 프로젝트와 학술대회 제출을 함께 진행하기 위한 팀 전달 자료다. 한 프로젝트, 하나의 공동 논문으로 취합한다. 팀원별 개인 원고는 최종 논문의 방법·결과를 작성하는 근거이며 별도 논문 다섯 편으로 제출하는 계획이 아니다.

## 담당자별 제출과 사실 확인

| 담당 | 현재 상태 | 제출할 자료 | 원고의 핵심 |
|---|---|---|---|
| 정회서 | 전처리 완료, 데이터 연결 검증 완료 | 데이터 사전·분할·통계·해시·생성 코드·데이터 원고 확인 | UCI 처리 구간, 사람 분리, fit 통계와 적용 순서 |
| 한윤섭 MLP | 이번 취합에서 새 결과 확인 대기 | 실제 구조·3seed 예측·지표·곡선·모델·설정·재로딩·원고 | 입력 펼치기 또는 561특징 여부, 구조·관찰·한계 |
| 최승빈 CNN | 이번 취합에서 결과 확인 대기 | 실제 구조·3seed 예측·지표·곡선·모델·설정·재로딩·원고 | 시간축 커널·풀링·집계·규모·오류 |
| 유재윤 RNN | 이번 취합에서 결과 확인 대기 | 실제 구조·3seed 예측·지표·곡선·모델·설정·재로딩·원고 | SimpleRNN 유닛·상태 초기화·수렴과 관찰 |
| 이봉헌 LSTM | 9회 검증 완료, 공동 기준 L01 3seed | 기존 Release의 실행 근거, 인용 연결 원고, 취합 초안 | 게이트·셀·검산·반복 결과·한계와 전체 취합 |

각자 목적, 실제 방법, 조건, 결과, 해석과 한계 순서의 5~8개 문단을 작성한다. 결과마다 run_id와 근거 파일을 적는다. 실제 문제는 재현 입력·관찰·원인·수정·재검증을 기록한다. 의도적 오류 예제는 그 사실을 표시한다. 각 역할 양식은 ../team-paper/templates/에 있다.

## 공통 비교표를 채우는 순서

1. 같은 캐시 SHA256, 통계 SHA256, 검증 사람 1·6·14·21·23을 사용했는지 대조한다.
2. sample_id·subject·true_label 순서와 라벨 0..5를 맞춘다. ID는 공식 train의 0 기반 번호이며 이전 MLP 1 기반 번호와 바로 합치지 않는다.
3. 모델별 실제 입력·구조·파라미터, seed, optimizer, 학습률, batch, early stopping, 선택 지표와 탐색 범위를 기록한다. 같은 조건은 실행 기록으로 확인한다.
4. validation_predictions.csv에서 같은 코드로 지표를 재계산한다. 기본 열은 sample_id, subject, true_label, predicted_label, probability_0부터 probability_5다. LSTM에는 logit_0부터 logit_5도 있다.
5. seed 평균과 표본 SD, 클래스별·사람별 F1과 support, confusion_matrix의 행=정답·열=예측을 취합한다.
6. LSTM은 L01의 세 seed를 공동 표에 넣고 L02·L03은 보조 분석으로 둔다. 공식 test는 합의와 모델 선택 고정 후 별도 수행한다.
7. 담당자별 사실 확인, 전원 원고 검토, 지도교수 검토를 거쳐 제출본을 작성한다.

학습률·batch가 같다는 것만으로 모든 비교가 공정해지는 것은 아니다. 입력·모델 규모·튜닝 예산을 함께 설명한다. 개인 PC의 시간 값을 모델 속도 순위로 비교하지 않는다.

## 최종 1~2쪽 논문의 편집안

제목과 초록에는 실제 연구 질문과 확인한 결과를 담는다. 서론은 문제와 선행 연구, 방법은 공통 데이터·분할·학습 조건과 네 구조, 결과는 네 모델 비교표와 핵심 오류, 결론은 관찰과 한계를 넣는다. 소형·Dropout 추가 결과는 공간이 허용될 때만 보조 분석으로 압축한다. 수학 검산 상세와 전체 seed 표는 수업 발표·개인 보고서·GitHub 근거로 연결한다.

TEAM_PAPER_DRAFT_KO.md와 Word는 LSTM 부분을 채운 내부 취합 초안이다. 다른 모델 결과와 최종 test가 없어 제출 가능한 완성 논문이라고 표시하지 않는다. 참고문헌 [7]의 행사 공고와 이 취합 절차는 실제 투고본에서 본문 밖 운영 기록으로 옮긴다.

## 대학생 학술 발표 구성

공식 공고는 대학생을 포스터로 안내한다. 과제 수업 PPT와 별도로, 결과 확정 후 학술 포스터를 만든다. 약 10분 발표·질의응답의 예시 배분은 문제·기존 연구 1분, 데이터·공정 비교 2분, 네 모델과 결과 3분, 오류·한계 1분, 질문 3분이다. 실제 운영 시간과 포스터 규격은 학회 안내를 따른다.

포스터는 문제, 방법, 네 모델 비교표, 핵심 오분류, 결론과 출처를 중심으로 구성한다. LSTM만 완료된 현재 상태에서는 최고 모델 표나 네 모델의 그래프를 만들지 않는다. 논문 채택·접수·발표자 등록을 완료했다고 표현하지 않는다.

## 공유 이력과 인용

수업 발표와 학술 발표가 같은 프로젝트라는 사실을 일관되게 기록한다. 연구의 데이터와 수치는 동일하게 유지하며, 팀의 성과와 개인 기여를 구분한다. UCI 데이터와 기존 모델 설명에 본문 인용을 연결한다. 강의자료 원본을 공개 저장소에 복제하지 않는다. 이전에 정식 출판된 원고가 있다면 투고 규정을 확인하고 공개 이력을 밝힌다. 문서 유사도 검사·최종 선행 연구 비교·최종 학회 제출은 아직 완료하지 않았다.
