## 공동 비교에 전달할 수치

**기준 R01:** validation Macro F1 0.7191 ± 0.0586, Accuracy 평균 73.56%. 공동 기준 비교에 사용할 RNN 행이다.

**개인 튜닝 선택 R02:** validation Macro F1 0.7715 ± 0.0675, Accuracy 평균 78.55%. 같은 validation에서 조건을 선택했으므로 독립 최종 성능으로 쓰지 않는다. 최고 seed만 선택하지 않았다.

네 모델 기준 비교는 M01·C01·R01·L01 세 seed의 결과이며, 다른 담당자의 실제 작업을 대신 완료한 것으로 표기하지 않는다. L01은 제공 main의 64유닛·Dense32 구조로 계획서의 32유닛 단순 LSTM과 다르다.
