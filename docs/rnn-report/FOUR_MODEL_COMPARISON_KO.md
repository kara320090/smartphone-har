# 네 모델 성능 비교 분석

같은 전처리 NPZ·저장 통계·S0 사람 분할·세 seed를 사용해 재실행했다. MLP·CNN·LSTM 행은 이번 RNN 담당 작업에서 실행한 비교용 보조 실험이다. 다른 담당자의 공식 제출 결과를 대신하지 않는다. validation은 학습 종료와 checkpoint 선택에 사용했다. 원자료는 four_model_comparison.csv와 paired_differences.csv다.

| 모델과 조건 | 파라미터 | Accuracy 평균 | Macro F1 평균 ± seed SD |
|---|---:|---:|---:|
| mlp M01 | 156,230 | 0.8667 | 0.8646 ± 0.0125 |
| cnn C01 | 14,054 | 0.8792 | 0.8784 ± 0.0073 |
| rnn R01 | 1,542 | 0.7356 | 0.7191 ± 0.0586 |
| lstm L01 | 21,222 | 0.8832 | 0.8813 ± 0.0195 |

LSTM의 평균 Macro F1은 CNN보다 0.0029 높았다. 세 번의 학습과 한 고정 validation 분할에서의 평균 차이이며 통계적 우월성이나 다른 사람 분할에서도 유지될 차이로 표현하지 않는다. LSTM과 CNN은 모델 규모·연산·출력 집계도 다르다.

| seed | MLP Macro F1 | CNN Macro F1 | RNN Macro F1 | LSTM Macro F1 |
|---|---:|---:|---:|---:|
| 2026 | 0.8753 | 0.8857 | 0.6621 | 0.8590 |
| 2027 | 0.8676 | 0.8712 | 0.7160 | 0.8952 |
| 2028 | 0.8509 | 0.8782 | 0.7792 | 0.8896 |

기준 RNN의 평균은 0.7191, seed SD는 0.0586였다. 이 실험에서는 다른 세 기준 구성보다 평균이 낮고 seed 변동이 컸다. RNN이라는 구조 전체의 한계나 기울기 소실의 발생을 의미하지 않는다. 기준의 파라미터가 1,542개이고 마지막 시점 출력만 사용한 조건도 함께 고려해야 한다.

별도 튜닝에서 선택한 R02의 평균 Macro F1은 0.7715로 R01보다 5.24 percentage points 높았다. 튜닝 조건은 동일 분할의 validation으로 선택했으므로 기준 네 모델 비교표에서 R01을 대체하지 않았다. 네 모델 모두 같은 탐색 예산으로 최적화한 결과가 아니다.

학습 시간은 run별 train_seconds로 보관했다. epoch 수가 조기 종료로 달라지고 RNN의 추가 gradient 진단 callback도 포함되어 있어 그 숫자를 순수 구조의 속도 순위로 해석하지 않는다. 추론 속도는 이번 비교에서 별도로 측정하지 않았다. 최종 test와 추가 사람 분할 검증은 후속 작업이다.
