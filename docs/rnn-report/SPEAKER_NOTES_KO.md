# 유재윤 RNN 발표 원고

약 5분 분량. 수치는 세 seed의 validation 결과이며 공식 test 성능이 아니다.

## 0분부터 40초 문제와 역할

저는 RNN 구현·학습·평가와 네 모델 성능 비교를 맡았습니다. 입력은 스마트폰 센서의 128시점과 9채널이며 여섯 행동을 분류합니다. 같은 사람의 중첩 구간이 학습과 검증에 동시에 들어가지 않도록 사람 단위로 나눴습니다.

## 40초부터 1분 30초 RNN 구조

기본 RNN은 현재 센서 입력과 직전 은닉 상태를 함께 받아 tanh로 새 상태를 계산합니다. 같은 가중치를 128번 사용합니다. 각 구간은 0 상태로 시작하고 다른 구간의 상태를 이어 쓰지 않습니다. 마지막 상태를 Dense 6으로 바꿔 여섯 logits를 출력합니다. 기준 은닉 32 모델은 1,542개 파라미터입니다. LSTM은 게이트와 셀 상태를 추가한 별도 구조입니다.

## 1분 30초부터 2분 10초 데이터와 학습

제공 캐시는 분할 완료 상태지만 시계열 표준화가 아직 적용되지 않았습니다. 저장 통계가 학습 5,577개에서 계산된 값과 같은지 확인하고 한 번 변환했습니다. 검증 사람은 1·6·14·21·23이며 1,775개입니다. Adam 0.001, batch 64, 최대 40 epoch, 검증 loss patience 6으로 학습하고 최저 손실 가중치를 복원했습니다. seed 2026·2027·2028을 모두 보고했습니다.

## 2분 10초부터 3분 10초 RNN 결과

기준 은닉 32의 평균 Macro F1은 0.7191이었습니다. 은닉 64는 0.7715, 은닉 64와 출력 Dropout 0.3은 0.7525였습니다. 사전에 정한 세 seed 평균 규칙에 따라 은닉 64를 선택했습니다. 선택 조건의 평균 Accuracy는 78.55%, F1의 seed 표본 SD는 0.0675입니다. 가장 높은 seed만 고르지 않았고 시연에는 seed 2026을 사용합니다. Dropout 비교는 같은 seed의 학습 전 가중치를 복사했습니다.

## 3분 10초부터 4분 15초 오류와 검증

선택 모델의 seed 2026에서는 걷기를 계단 오르기로 예측한 143개가 가장 큰 방향성 혼동이었습니다. 같은 사람·같은 정답 행동의 오류와 성공 파형을 함께 보관했습니다. 초기 고정 배치의 기울기는 유한성을 확인한 진단이며 시점별 기울기 소실을 측정한 것은 아닙니다. 학습 loss의 실제 변동도 기록했지만 원인을 폭주로 단정하지 않았습니다. 작은 RNN의 30개 파라미터 수치미분, 50개 코드 테스트, 모든 저장 모델의 검증 1,775개 재로딩을 통과했습니다.

## 4분 15초부터 5분 네 모델과 한계

같은 제공 데이터로 추가 실행한 기준 비교의 평균 Macro F1은 MLP 0.8646, CNN 0.8784, RNN 0.7191, LSTM 0.8813입니다. LSTM과 CNN 평균 차이는 작고 세 학습의 변동도 있습니다. 네 구조의 규모와 탐색 예산이 달라 원인을 하나로 설명하지 않았습니다. RNN 튜닝 결과를 기준 비교표에 섞지 않았습니다. 이번 결과는 고정 사람 분할에서의 개발 결과이며, 최종 test는 팀에서 평가 대상과 시점을 정한 다음 진행해야 합니다.
