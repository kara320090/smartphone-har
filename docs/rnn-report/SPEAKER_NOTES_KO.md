# 유재윤 RNN 발표 대본(약 5분)

## 0:00~0:45 문제와 입력

저는 RNN을 담당한 유재윤입니다. 스마트폰의 9개 센서 채널을 128시점씩 받아 여섯 행동을 분류했습니다. 제공 데이터에 저장된 학습 통계를 한 번 적용했고, 피험자가 겹치지 않는 학습 16명·검증 5명으로 개발했습니다.

## 0:45~1:40 구조와 조건

기준은 은닉 32개의 SimpleRNN이고 마지막 은닉 상태를 Dense 6으로 변환합니다. 각 구간에서는 상태를 0으로 초기화해 다른 사람이나 다음 구간으로 상태가 넘어가지 않게 했습니다. Adam 0.001, 배치 64, 최대 40에포크로 학습하며 검증 손실이 개선되지 않으면 조기 종료하고 최선 가중치를 복원했습니다.

## 1:40~2:40 튜닝과 결과

기준 R01과 은닉 64의 R02, 출력 Dropout 0.3의 R03을 각각 세 seed에서 실행했습니다. 기준의 검증 Macro F1은 0.7191 ± 0.0586, 튜닝에서 선택한 R02는 0.7715 ± 0.0675였습니다. 평균은 약 5.24%p 개선됐지만 고정 검증셋을 선택에 사용한 개발 결과입니다. 기준 결과와 튜닝 결과를 분리했고 가장 잘 나온 seed만 고르지 않았습니다.

## 2:40~3:40 곡선과 오류

R02 seed 2026은 6에포크가 최선이었고 12에포크에서 종료했습니다. 같은 에포크의 학습·검증 지표로 과적합을 살폈습니다. 가장 큰 혼동은 걷기를 계단 오르기로 분류한 143개였습니다. 같은 사람·같은 정답에서 오류와 성공 파형 3쌍을 비교했습니다. 파형이나 손실 증가만으로 오류 원인이나 기울기 폭주를 확정하지 않았습니다.

## 3:40~4:30 확인과 재현

작은 RNN의 중심차분과 자동미분을 대조했고 최대 오차는 약 1.875e-11이었습니다. 모델 구조·상태 초기화·입력 검증을 테스트했고, 9개 저장 모델을 검증 전체에서 다시 불러온 기록을 보관했습니다. Git에는 코드·표·그래프·원고, Release에는 모델·초기 가중치·통계·데이터를 올렸습니다.

## 4:30~5:00 해석과 남은 팀 작업

표준편차는 한 피험자 분할의 학습 seed 변동을 나타냅니다. 공식 test는 평가하지 않았고 최종 대상과 공통 조건을 동결한 뒤 평가해야 합니다. 팀 전체 비교는 각 담당자의 공식 결과를 받아 조건을 확인한 뒤 취합해야 합니다.
