# 유재윤 RNN 예상 질의응답

1. **어떤 RNN인가요?** tanh SimpleRNN 한 층이며 마지막 상태를 Dense 6에 넣습니다. 기준 은닉 32, 튜닝 은닉 64입니다.
2. **구간 사이 상태를 이어 쓰나요?** 아닙니다. stateful=False로 각 구간의 초기 상태는 0입니다.
3. **입력과 라벨은?** float32 (N,128,9), int64 0–5의 여섯 행동입니다.
4. **이중 정규화를 막았나요?** 제공 배열이 표준화 전임을 확인하고 학습 통계를 한 번 적용했습니다. 어댑터가 데이터 해시와 통계 일치를 검사합니다.
5. **사람 정보가 입력에 들어가나요?** 사람 ID는 분할·오류 분석에만 사용합니다. 학습과 검증 사람은 겹치지 않습니다.
6. **왜 세 seed인가요?** 초기화·학습 순서 변동을 확인하려고 합의한 세 seed를 모두 보고했습니다. SD는 표본 SD이지 피험자 모집단 신뢰구간이 아닙니다.
7. **최종 조건은 어떻게 정했나요?** 세 seed 검증 Macro F1 평균으로 R02를 선택했습니다. 기준 R01과 튜닝 결과를 분리했습니다.
8. **Dropout 비교는 공정한가요?** R03은 같은 seed R02의 학습 전 가중치를 복사했습니다. Dropout에 따른 학습 경로 차이는 남으므로 단일 원인으로 과장하지 않습니다.
9. **저장은 어느 에포크인가요?** 검증 손실 최저 가중치입니다. R02 seed 2026은 6에포크가 최선, 총 12에포크 학습입니다.
10. **과적합은 어떻게 확인했나요?** 같은 에포크의 학습·검증 손실과 정확도, 후반 추이를 봤습니다. 후반 악화와 양립하지만 원인을 확정하지 않습니다.
11. **기울기 소실이나 폭주를 확인했나요?** 시점별·실제 갱신 배치 기울기를 저장하지 않았으므로 입증하지 않았습니다. 초기 고정 배치 진단은 별도 수치 확인입니다.
12. **주요 오분류는?** R02 seed 2026에서 걷기→계단 오르기 143개입니다. 같은 사람·같은 정답의 오류/성공 파형 3쌍을 대조했습니다.
13. **모델을 다시 불러오면 같은가요?** 검증 1,775개 전체 새 프로세스 예측을 저장 예측과 허용오차 내 비교한 9회 기록이 있습니다.
14. **공식 test 결과인가요?** 개발 검증 결과입니다. 공식 test는 미평가이며 팀 합의로 최종 조건을 고정한 다음 평가합니다.
15. **팀 전체 비교가 포함되나요?** 이번 게시 범위는 RNN 9회입니다. 각 담당자의 공식 결과·동일 조건 인계 후 공동 비교표를 작성해야 합니다.
16. **누가 작성했고 제출 전에 무엇을 확인하나요?** 담당자는 유재윤이며 Codex 보조로 구현·분석·문서를 작성했습니다. 담당자가 코드·수치·해석을 이해하고 최종 원고·발표를 검토해야 합니다.
