# 유재윤 RNN GitHub 게시 완료

2026년 10월 13일 기준. 한글 이름은 **유재윤**, 영문 표기가 필요한 경우 **Yu jaeyun**을 사용한다. 설명·원고·그래프·실행 노트북을 한글 중심으로 정리했다.

- [RNN 전용 PR #3](https://github.com/kara320090/smartphone-har/pull/3): 코드·설정·원자료·노트북·한글 문서
- [RNN 전용 Release](https://github.com/kara320090/smartphone-har/releases/tag/yu-jaeyun-rnn-v1): 모델·초기 가중치·공유 입력 데이터·통계·전체 재현 묶음
- 브랜치: feat/yu-jaeyun-rnn
- 정식 실험: R01·R02·R03 × seed 2026·2027·2028, 총 9회

직접 수행한 보조 CNN을 비롯한 다른 모델 구현·실험·비교표는 이번 RNN 게시 범위에서 제외했다. 팀 main의 다른 담당자 모델과 설정은 유지했다. 이전 혼합 PR #2는 닫았고 이전 Release·태그·브랜치는 제거했다. 닫힌 PR 기록과 로컬 원본은 이력으로 남아 있다.

통합 테스트 68개, RNN 전용 재현 묶음 테스트 11개, 세 RNN 조건의 새 연결 점검이 통과했다. 저장 모델 9개 모두 검증 1,775개 전체를 새 프로세스로 다시 불러와 확인했고, 한글 노트북의 코드 5개 셀이 정상 실행됐다. ZIP과 파일 목록·체크섬의 서버 해시가 로컬 파일과 일치했다.

기준 R01의 검증 Macro F1은 0.7191 ± 0.0586, 튜닝 선택 R02는 0.7715 ± 0.0675다. 공식 test는 미평가다. main 병합은 아직 하지 않았으므로 팀 검토 후 PR을 반영하면 된다. 최종 test·팀 전체 공식 모델 비교·통합 논문과 발표 슬라이드는 공동 조건과 최종 대상 결정 후 진행할 작업이다.

전체 모델·공유 데이터는 Git 커밋에 중복해서 넣지 않고 Release에서 받는다. 원 실행 코드 해시와 선별 게시 코드의 관계는 SOURCE_PROVENANCE_KO.md, 파일별 해시는 Release의 RNN_RELEASE_MANIFEST.json과 SHA256SUMS.txt에 있다.
