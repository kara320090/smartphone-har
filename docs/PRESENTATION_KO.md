# 기준모델과 학습 파트 발표 원고

약 4분 분량의 설명 초안이다. 실험 수치는 `reports/RESULTS_KO.md`에서 읽고, 발표 전 노트북을 직접 실행해 본다. 아래는 개인 경험을 대신 주장하는 문장이 아니라 구현과 측정 근거를 설명하는 원고다.

## 0분부터 1분 모델과 입력

기준모델은 두 개의 MLP입니다. 첫 번째는 UCI가 제공하는 561개 특징을 입력으로 받고, 두 번째는 128시점 9채널 신호를 1,152개 값으로 펼칩니다. 둘 다 128개와 64개의 ReLU 은닉층 뒤 여섯 행동의 점수를 출력합니다. 파라미터 수는 각각 80,582개와 156,230개입니다.

특징 MLP는 사람이 설계한 요약 특징을 사용하고, 시계열 MLP는 센서 구간 자체를 사용합니다. 입력 표현과 모델 크기가 함께 바뀌므로 두 점수의 차이를 구조 한 가지 원인으로 설명할 수 없습니다.

## 1분부터 2분 역전파와 공통 학습

모델의 마지막 출력은 확률이 아니라 logits입니다. 교차엔트로피에 from_logits=True를 적용하고, 화면이나 평가에서 softmax로 확률을 얻습니다. 역전파는 손실의 기울기를 구하는 과정이고 Adam은 그 기울기를 이용해 가중치를 갱신하는 방법입니다.

입력 2, 가중치 3, 편향 1, 목표 10인 작은 예제에서 예측은 7이고 손실은 4.5입니다. 손계산과 자동미분으로 가중치 기울기 -6, 편향 기울기 -3을 확인했습니다. 2→3→2 tanh MLP의 전체 17개 파라미터도 NumPy 역전파, 중심차분, 자동미분으로 비교했습니다. 상세 오차는 수학 검증 표에 있습니다.

## 2분부터 3분 조건 통제와 관측 결과

학습 16명과 검증 5명을 분리하고, 표준화와 PCA는 학습 사람에서만 계산했습니다. 같은 학습 함수에 Adam, 배치 64, 최대 40 epoch와 검증 손실 기준 조기 종료를 적용했습니다. 최저 검증 손실의 가중치를 복원한 뒤 macro F1로 설정을 비교했습니다.

기본 MLP에서 표준화 제거, Dropout 0.3, 두 학습률, PCA 95%를 각각 바꿨습니다. 결과표에서 E02 점수와 비교 조건 두 개를 골라 설명합니다. 학습 곡선에서는 학습 손실과 검증 손실이 함께 줄었는지, 어느 시점부터 차이가 벌어졌는지를 근거로 말합니다. 가장 높은 점수 하나만 제시하지 않습니다.

## 3분부터 4분 재현과 한계

각 실행에서 모델만 저장하지 않고 전처리 통계, 채널·클래스 순서, 분할 ID, 설정, 학습 곡선과 표본별 예측을 함께 저장했습니다. 새 프로세스에서 원 검증 입력부터 다시 변환해 확률과 라벨이 같은지 확인합니다. TFRecord 실습은 학습 표본 200개를 저장하고 다시 읽어 값·모양·정답·ID가 정확히 같은지 검사합니다.

현재 비교는 seed 2026과 검증 사람에 대한 결과입니다. 다른 seed 반복과 공식 시험 평가는 전체 팀의 평가 단계에서 수행합니다. PCA의 차원 축소가 항상 더 좋은 분류를 뜻하지 않으며, 검증 점수가 높다고 새로운 기기·착용 위치에서도 같은 성능을 보장하지 않습니다.

## 예상 질문

| 질문 | 답의 핵심 |
|---|---|
| 왜 마지막 층에 softmax가 없는가 | from_logits=True 손실과 맞추고, 확률 변환은 평가·추론에서 수행 |
| 왜 사람별로 분리했는가 | 같은 사람의 겹치는 구간·개인 특성이 양쪽에 섞여 새 사람 성능이 과장되는 것을 줄임 |
| 역전파와 Adam은 무엇이 다른가 | 기울기 계산과 파라미터 갱신 방법의 차이 |
| 최선 epoch와 종료 epoch가 왜 다른가 | 개선을 기다리는 patience 뒤 종료하고 과거 최선 가중치를 복원 |
| macro F1를 쓰는 이유는 | 표본 수와 관계없이 6개 행동을 같은 비중으로 평균 |
| PCA 결과를 어떻게 해석하는가 | 분산 보존 목적과 정답 구분 목적은 다르며 입력 차원·파라미터 수도 변함 |
| 높은 seed 결과만 고르면 되는가 | 선택 편향이 생기므로 정한 seed와 반복 평균·표준편차를 보고 |
| 저장 모델로 학습을 그대로 재개할 수 있는가 | 이번 저장물은 최선 가중치 평가용이며 optimizer 상태와의 정확한 재개는 지원하지 않음 |

## 봉헌님이 직접 확인할 것

1. 첫 번째 노트북의 scalar 기울기를 직접 계산한다.
2. 두 번째 노트북을 실행하고 model.summary, 입력 shape, 저장 파일을 확인한다.
3. 결과표와 학습 곡선에서 예상과 다른 조건 하나를 골라 가능한 이유를 설명한다.
4. 팀원에게 저장물 한 폴더를 전달하고 그 사람의 환경에서 실행을 함께 확인한다.
