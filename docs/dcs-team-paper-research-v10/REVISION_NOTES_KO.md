# v9.1에서 v10으로 바꾼 근거

| 기존 한계 | 추가한 작업 | v10에 반영한 내용 |
|---|---|---|
| LR와 시계열 NN의 입력 표현이 다름 | 같은 18개 통계 특징·3상태 목표의 FMLP3 3seed | 표현을 맞춘 지정 구성 비교; LR3 0.9994, FMLP3 0.9986±0.0002 |
| 6종 예측을 병합한 점수만으로 직접 3상태 학습을 판단하기 어려움 | MLP/CNN/RNN/LSTM의 직접 3상태 12회 추가 | 6종·병합·직접 학습을 분리한 표 |
| 파라미터 수만으로 비용을 판단 | 29개 모델을 동일 CPU에서 순차 실측 | 시간 2범위, 500회 원시 기록, 수치 배열·저장 파일·RSS 분리 |
| 개발 검증 점수만 있음 | 조건 고정·커밋 후 공식 test 9명 평가 | 학습 16/검증 5/test 9명, test 원본 대조, 재예측·지표 감사 |
| 개발 자료에서의 무오류가 일반화로 읽힐 수 있음 | 공식 test LR3 오류 2건 확인 | 무오류 표현 제거, 해당 샘플 ID 보충자료 공개 |
| 활용 결론이 추상적 | 출력 요구·실측 성능·비용을 연결 | 상태 요약은 통계·선형 기준선부터, 세부 기록은 6종 성능으로 판단 |

원고는 공식 대학생 양식 2페이지를 유지했다. 그림 1은 대조·사람 분할, 그림 2는 공식 test F1과 CPU 처리 비용이며 참고문헌은 핵심 3개다. 실험의 전체 표·사람별 점수·오류·메모리는 보충자료에 남겼다. 사사 문구는 사용자 지정 컴퓨터비전 논문의 문장을 그대로 유지했다.

이전 원고의 타 대학 논문 비교는 구조와 설명 방식의 참고 기록으로 보존한다. 다른 논문의 문장·그림·실험 결과를 재사용하지 않았고 수상 가능성이나 새로운 알고리즘을 주장하지 않는다.
