# 공식 test를 반영한 공동 논문 v10

**스마트폰 활동 요약을 위한 출력 수준별 분류 성능과 추론 비용 비교**

2026-10-19 · 이봉헌, 유재윤, 정회서, 한윤섭, 최승빈 · 지도교수 황세웅

대학생 공식 양식의 **2페이지 한글 원고**다. 보완 학습 15회, 고정한 29개 모델의 공식 test 평가와 재로딩을 완료한 결과를 반영했다. 원고에는 실험 설계 그림, 6종·병합·직접 3상태 비교표, 성능·CPU 비용 그림을 넣었다. 사용자 지정 사사 문구와 저자 순서를 유지했다. 공동저자·지도교수 검토 후 제출할 초안이며, 학회에 접수한 상태는 아니다.

## 이번에 확인한 결과

공식 test는 학습·검증과 사람이 겹치지 않는 9명·2,947구간이다. 통계 특징 18개를 사용하는 LR3의 Macro F1은 **0.9994**, 오류는 **2개**였다. 같은 특징·목표를 사용하는 FMLP3는 **0.9986 ± 0.0002**였다. 네 시계열 NN 모두 직접 3상태 학습의 평균 F1이 기존 6종 예측을 병합한 경우보다 높았다. 이 결과를 원래 6종 분류 성능의 개선이나 통계적 동등성으로 표현하지 않는다.

준비된 센서 구간부터 결과 반환까지 동일 PC에서 측정한 중앙값은 LR3 **0.073ms**, FMLP3 **1.043ms**였다. 센서 수집·UCI 필터링·구간 생성과 초기 로딩은 제외했고 NumPy/TF 런타임 차이가 포함된다. 128개 시점의 입력 길이는 50Hz에서 **2.56초**이며, 계산 시간 0.073ms가 첫 센서 관측부터의 전체 지연을 뜻하지 않는다.

따라서 이 데이터 조건의 활동 요약에는 통계·선형 기준선을 먼저 검토할 근거가 생겼다. 계단·앉기 등 세부 행동을 구분해야 하면 별도의 6종 성능으로 판단해야 한다. 휴대 위치·기기 변화, 연속 일상 입력, 실제 앱·전력은 후속 검증 대상이다.
