# 공식 논문 양식 적용 및 확인 기록

기준은 사용자가 2026년 10월 9일 제공한 두 HWP 양식과 학회 안내이다. 문서 안의 예시 저자·본문·그림·감사의 글은 실제 연구 자료가 아니므로 삭제했다.

## 일반 양식과 대학생 양식

| 항목 | 일반 양식 | 대학생 양식 및 이번 적용 |
| --- | --- | --- |
| 제목·저자·소속 | 국문·영문 병기 | 국문 구성 유지 |
| 저자 관련 말미 | 교신저자 | 지도교수 Supervisor란 유지 |
| 앞부분 | 국문 요약 | 별도 요약란 없음, 연구 배경에서 목표·범위 설명 |
| 본문 | 서론·연구·평가 등의 예시 | 연구 배경·연구 내용·결과·제한·결론으로 구성 |

## 적용한 서식

- [x] 대학생 원본의 A4 용지와 여백 유지: 좌·우 20 mm, 위·아래 25 mm. 원본 HWP 단위와 재로딩 문서 단위를 대조했다.
- [x] 전폭 제목란과 2단 본문, 원본 머리말을 보존했다.
- [x] 본문 휴먼명조 10 pt, 양쪽 정렬과 원본 들여쓰기·줄 간격 유지.
- [x] 표 제목 휴먼명조 9 pt, 가운데 정렬. 표 안 글자는 9 pt로 구성했다.
- [x] 표는 글자처럼 취급. 제목은 표 밖의 일반 문단이며 표 전후에 빈 문단이 있다.
- [x] 예시 이름·소속·이메일·그림·참고문헌·감사의 글·작성 지침을 원고 본문에서 삭제했다.
- [x] 알 수 없는 이름·순서·소속·이메일·지도교수는 ‘확인 필요’로 두었다.
- [x] 문서 내부 저자 메타데이터도 ‘저자 확인 필요’로 바꿨다. 원본 양식의 교수 이름을 새 원고 저자로 남기지 않았다.
- [x] HWP 저장 후 한글에서 다시 로딩하여 전체 원고와 표 수치, 2쪽 분량을 확인했다.
- [x] 한글 내장 미리보기로 두 쪽을 모두 검토했다. 둘째 쪽은 동일 서식의 메모리 복제본으로 렌더링하고 원본의 17개 본문 단락·표 셀 줄 배치 정보와 정확히 일치하는지 검사했다.
- [x] 첫 미리보기에서 둘째 표 제목이 쪽 끝에 떨어지는 문제를 발견했다. 제목 문단의 다음 문단과 함께 유지 설정을 적용해 제목과 표를 둘째 쪽으로 함께 이동시킨 뒤 재검증했다.

## 연구 내용 확인

- [x] 표의 LSTM 수치는 기존 검증 결과 CSV에서 생성했다.
- [x] 팀원 3개 모델의 결과는 ‘취합 대기’로 남겼다.
- [x] validation 결과임을 제목란과 본문에 표시했다.
- [x] L01을 공동 비교용 기준 모델로 유지했다.
- [x] 작은 수동 역전파 검산과 Keras를 이용한 실제 학습을 구분했다.
- [x] 의도적인 미분 오류 주입을 실제 학습 결함으로 표현하지 않았다.
- [x] 기존 CNN·LSTM 행동 인식 연구를 인용해 알고리즘 최초 제안으로 표현하지 않았다.
- [ ] 팀원 모델과 조건을 취합하고 결과·초록·결론을 최종 확정한다.
- [ ] 저자·저자 순서·소속·교신저자·이메일·지도교수를 확인한다.
- [ ] 최종 인용·유사도·관련 연구·AI 보조 사용 표기와 투고 적합성을 지도교수와 검토한다.
- [ ] 최종 수정 후 2쪽 전체를 다시 확인하고 공식 접수 경로로 제출한다.

## 문서 제작 중 발견한 연결 문제

한글의 HWPML 문자열 입력은 UTF-8 선언으로 만든 XML을 불러올 때 성공값을 반환해도 내용이 비어 있었다. 저장 파일을 다시 불러와 예상 본문을 검사해 이를 탐지했다. 원본이 사용하는 UTF-16 선언·인코딩으로 맞춘 뒤 전체 본문과 표를 재대조했다. 빈 초안은 덮어써 최종 파일에는 남아 있지 않는다. 이 문제는 문서 제작의 인코딩 연결 문제이며 LSTM 학습 결함과 관계없다.

한글 파일 경로 승인 모듈은 공식 배포 DLL의 비트 수·직접 로드·export·레지스트리를 확인했지만 등록 결과가 False였다. 원본 양식 읽기와 최종 HWP 쓰기는 공식 `SetTextFile`·`GetTextFile`의 메모리 입력·출력으로 처리했다. `CreatePageImage`가 파일 접근 확인에서 대기해 사용자에게 조작을 요청했으나, 이후 한글의 내장 미리보기로 검증할 수 있는 방식을 완성해 요청이 필요 없다고 안내했다. 둘째 쪽 미리보기는 원본의 줄·표 셀 배치와 대조하여 사용했다. 보안 설정을 끄거나 원본 양식을 바꾸지 않았다.

원본 두 양식과 수업 자료는 GitHub에 게시하지 않는다. 한글 결과 파일, 수정용 MD와 검증 기록만 인계한다.
