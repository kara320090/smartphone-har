# DCS 2026 대학생 논문경진대회 한글 취합 초안

사용자가 제공한 **대학생 공식 HWP 양식**에 현재 팀 원고를 옮긴 2쪽 초안이다. 현재 확인된 실험은 이봉헌 담당 LSTM 9회이며, MLP·CNN·RNN 결과와 저자 정보는 아직 취합하지 않았다. 이 파일은 학회에 제출하지 않았다.

## 파일

- `DCS_2026_대학생_팀논문_취합초안.hwp`: 실제 한글 바이너리 파일. 대학생 양식의 제목란, 머리말, 글꼴, 여백과 본문 2단을 유지했다.
- `DCS_STUDENT_PAPER_DRAFT_KO.md`: 같은 초안의 검토·수정용 Markdown 원고.
- `TEMPLATE_CHECKLIST_KO.md`: 일반·대학생 양식의 차이, 적용 내역과 최종 확인 사항.
- `VERIFICATION.json`: 저장 후 한글 재로딩·분량·본문·표·수치 검증 기록.
- `SHA256SUMS.txt`: 이 묶음의 파일 무결성 확인값.

## 제출 형식

학회가 사용자에게 보낸 안내는 **PDF가 아닌 한글 파일 제출**과 분야별 양식 구분을 명시한다. 대학생 논문경진대회용으로 준비했으므로 대학생 양식을 사용했다. 일반 양식의 국문·영문 저자란과 요약을 학생 양식에 임의로 추가하지 않았다. 원본 두 양식은 수정하지 않았으며 이 저장소에는 업로드하지 않았다.

학생 양식은 국문 제목·저자·소속·이메일·지도교수란과 2단 본문으로 구성되어 있다. 양식의 작성 지침은 최대 2쪽, 표·그림의 글자처럼 취급, 표·그림 제목의 일반 문단 작성, 꼬리말 페이지 번호 금지를 안내한다. 각 장 내용은 유연하게 구성할 수 있어 연구 배경, 연구 내용, 실험 결과 및 검증, 제한 조건 및 활용, 결론으로 정리했다.

## 최종 투고 전 남은 작업

1. 저자 명단과 순서, 학교·학과, 이메일, 교신저자, 지도교수 및 발표자를 실제 참여자와 지도교수에게 확인한다. 역할표의 이름 순서를 저자 순서로 추정하지 않았다.
2. MLP·CNN·RNN의 실제 구조, 입력 표현, 학습 조건과 반복 결과를 받아 표 1을 완성한다. 다른 데이터 표현이나 분할이면 같은 비교라고 표시하지 않는다.
3. 현재 validation은 epoch 선택에도 사용했다. 공식 test 평가 여부와 시점은 팀에서 선택 조건을 고정한 뒤 결정한다. 지금 수치를 최종 test 성능으로 바꾸어 적지 않는다.
4. 실제 결과에 맞춰 제목·연구 목표·결론과 분량을 다시 검토한다. 결과를 더 넣어 2쪽을 넘기면 설명·표를 편집하고 다시 렌더링한다.
5. 인용, 관련 연구와 기여 범위, 저자 책임 및 AI 보조 사용 표기를 지도교수와 학회 요구에 맞춰 검토한다. 초안 작성·코드 검증·문서 정리에 Codex 보조를 사용했다. 최종 유사도 검사와 종합적인 신규성 검토는 아직 완료하지 않았다.
6. 최종 HWP를 한글에서 열어 2쪽 전체와 표의 배치를 확인한 뒤 공식 접수 경로로 제출한다. 이메일 안내를 받았다는 이유로 이메일로 논문을 보내지 않는다.

## 결과와 기존 자료

저장된 실제 HWP를 한글에서 다시 불러와 본문·표와 2쪽 분량을 검증했다. 첫 쪽의 한글 내장 미리보기와 둘째 쪽의 임시 메모리 복제본 미리보기를 모두 확인했다. 둘째 쪽은 원본 HWP의 17개 본문 단락과 표 셀의 줄 배치 정보가 복제본과 정확히 일치함을 대조했다. 세부 방법은 `VERIFICATION.json`에 기록했다.

L01은 공동 비교용 기본 LSTM이며 개발용 validation Macro F1은 **0.8813 ± 0.0195**, Accuracy 평균은 **0.8832**이다. ±는 동일 사람 분할에서 seed 3회의 표본 SD이다. L02·L03의 보조 실험이 L01의 대표 지위를 바꾸지 않는다. 원고의 표는 `reports/lstm/summary.csv`에서 자동으로 생성했다.
