# 구현 과정과 판단 기록

작성일은 2026년 9월 29일이다. 수 주 동안 겪은 경험을 재구성한 일지가 아니라, 기존 구현에 대한 이번 보강 작업의 실제 순서다. 최초 정상 학습과 후속 검증은 별도 기록으로 보존했다. JSON 시각은 UTC이며 한국 시간은 9시간을 더한다.

## 기존 결과를 먼저 보존

v1은 seed 2026의 7조건, 테스트 8개, 모델 7개 재로딩, 실행한 노트북 3개를 포함했다. 기준 소스와 보고서는 커밋 `7aec3ac` 및 v1 릴리스에 남겼다. 이를 덮어쓰면 수정 전후의 비교 근거가 사라지므로 새 학습은 별도 폴더에서 실행했다.

당시에도 단일 seed를 보편적 우월성으로 주장하지 않았다. 이번 반복 검증은 기존에 과장된 주장을 했던 것처럼 사건을 꾸미기 위한 작업이 아니다.

## 분할 번호를 정상화하는 코드에서 검증 누락 발견

의문은 “팀원의 전처리 모듈이 잘못된 분할 번호를 주어도 학습이 진행될까?”였다. 합성 18행 입력으로 소수, 음수, bool 등을 전달했다. 기존 코드가 소수를 잘라서 정수로 만들고 음수는 배열 뒤의 행을 선택했다. dtype 변환을 검증으로 대신할 수 없다는 원인을 확인했다.

먼저 회귀 검사를 작성하고 수정 전 실패를 저장했다. 이후 정수형·차원·범위·중복 검사를 변환과 fit 이전으로 옮겼다. 매우 큰 unsigned 값도 cast 전에 검사했다. 정상 입력을 고치는 기능이 아니라 잘못된 입력을 명확히 거부하는 계약으로 정했다.

## 길이가 같은 자료도 순서가 다를 수 있음을 재현

raw_validation의 행을 역순으로 바꾸어도 기존 길이 검사가 통과했다. 저장 전처리를 적용한 결과와 실제 모델 입력의 최대 절대 차이가 11.672906875610352였다. 길이 일치만으로 저장물 재현용 입력이 올바르다고 판단할 수 없었다.

저장 전처리로 raw_validation을 다시 변환하고 shape·유한값·전체 수치를 비교하도록 수정했다. 두 자료가 함께 잘못 바뀐 경우의 의미적 진실성은 이 검사 범위 밖이라고 문서에 남겼다.

## 정상 경로를 유지하는지 확인

신규 16검사는 수정 전 15실패·1통과였다. 수정 후에는 기존 8개까지 포함한 24개가 통과했다. 검증 값에 큰 상수를 더했을 때 학습 통계가 변하지 않는 검사도 포함했다. 실패 수를 독립 버그 수로 부풀리지 않았다.

수정과 반복 계획은 `47bc6f3`에 기록했다. 실제 7조건을 seed 2026·2027·2028에서 실행했다. 새 seed 2026의 예측은 최초 v1의 예측과 모두 일치해 정상 입력에 대한 결과가 유지됨을 확인했다.

## 같은 seed만으로 초기값 통제가 충분한지 재검토

E02와 E08을 같은 seed에서 생성하여 Dense 배열을 비교했다. 첫 층은 같았지만 이후 층은 달랐다. 초기값까지 같다고 가정하면 Dropout 비교의 설명이 실제 코드보다 강해지는 문제가 있었다.

각 Dense에 별도 seed를 부여하는 대안과 배열 복사 대안을 검토했다. 현재 모델 정의를 유지하면서 전체 초기값의 일치를 직접 검증할 수 있는 복사를 선택했다. E08W 추가 계획을 `aaa5d3f`에 기록한 뒤 같은 세 seed에서 학습했다. 학습 전 배열과 해시 일치를 확인했다.

E08W 평균 F1은 0.8740이었다. 모든 seed에서 기존 E08보다 좋아진 것은 아니며, E02 평균 0.9046보다 낮았다. 초기값 일치는 통제 조건이고 성능 향상 보장이 아니라는 점을 결론에 반영했다.

## 검증 도구 자체도 점검

기존 tanh 검증에 ReLU·6logits·평균 교차엔트로피의 작은 네트워크를 추가했다. 46파라미터를 세 h 값에서 중심차분과 비교했다. 평균 미분에서 /B를 의도적으로 누락시켜 검사에서 잡히는지도 확인했다.

ReLU 0의 중심차분 0.5와 TF의 선택값 0은 비미분점의 차이였다. 이를 라이브러리 오류라고 적지 않았다. 큰 logits에서는 최대값을 뺀 softmax도 작은 확률의 underflow를 남길 수 있어 logits 기반 logsumexp 손실까지 비교했다. 두 사례는 실제 학습 사고가 아닌 명시적인 수학 대조다.

## 결과에 맞게 결론의 강도 조정

seed 2026은 E02, 2027은 E10, 2028은 E07이 기존 7조건 중 가장 높았다. E02와 E07 평균 차이는 약 0.12%p였다. 단일 최고 점수를 제시하는 데서 멈추지 않고 seed별 대응 차이, 평균·SD, 사람별 성능을 함께 정리했다.

같은 검증 사람 5명을 반복 사용했으므로 SD를 새 사람 모집단의 신뢰구간으로 표시하지 않았다. 공식 test는 평가하지 않았다. 팀의 최종 비교·통합·시연을 완료했다고 표시하지 않았다.

## 전달 가능한 근거로 보존

새 모델 24개를 새 프로세스에서 다시 불러 원본 검증 자료에서 예측했다. 클래스·확률·지표·파일 해시를 확인하고 실행별 설정·로그·전처리·표본 ID를 보관했다. 코드, 21쪽 심화 보고서, 20장 PPT, 원고, 질의응답 34개, 재현 안내를 함께 제공한다.

AI 보조로 구현·실행·문서 정리를 수행했다. 발표자는 실제로 검토하고 이해한 범위를 바탕으로 설명하고, 하지 않은 팀 활동이나 장기간의 시행착오를 개인 경험처럼 추가하지 않는다.
