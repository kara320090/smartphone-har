## 1 주제와 비교 범위

가제는 **스마트폰 센서 기반 MLP·CNN·RNN·LSTM의 사용자 독립 행동 인식 성능 비교**다. 동일한 센서 구간과 사람 분할에서 네 모델의 분류 성능, 학습 seed에 따른 변동, 모델 규모를 비교한다. RNN은 LSTM과 구분되는 기본 순환신경망인 **SimpleRNN**을 뜻하며 실제 구현을 명시한다.

| 항목 | 공통 기준 |
|---|---|
| 데이터 | 완료된 UCI HAR 전처리 결과를 공동 사용 |
| 핵심 입력 | 같은 128×9 시계열 구간. MLP만 모델 내부에서 펼침 |
| 비교 모델 | MLP, 1D CNN, SimpleRNN, LSTM |
| 우선 지표 | 6클래스 Macro F1, Accuracy, 클래스별 F1, 사람별 성능 |
| 추가 비교 | 파라미터 수, 학습 곡선, 동일 장치에서 측정한 추론 시간 |
| 기본 반복 | 공통 고정 분할 × 4모델 × 3학습 seed = 12회 개발 실험 |
| 선택 확장 | 추가 사람 분할 2개까지 포함하면 총 36회. 사전 합의 후 진행 |

561특징 MLP, PCA·군집, AE는 보조 자료로 둘 수 있다. 561특징과 시계열은 입력 표현이 달라 구조 효과만의 비교로 해석하지 않는다. 특정 모델의 우승이나 LSTM의 장기 의존성 학습 성공을 결과 전에 정하지 않는다.

**제출물:** 로딩 안내, data_dictionary.md, 분할 목록, data_distribution.csv, 전처리 파일과 버전·출처, 개인 원고. 이미 있는 자료는 경로를 연결해도 된다.

## 4 한윤섭 — MLP

- 같은 `(N,128,9)` 입력을 모델 내부에서 1,152차원으로 펼쳐 분류한다. 기존 E03은 재사용 후보이며 새 데이터 연결을 확인한다.
- 은닉층 수·차원, 활성화, Dropout, 출력, 파라미터 수를 기록한다. 펼친 벡터로 처리하는 구조를 설명한다.
- 공통 규약의 세 seed를 실행하고 학습·검증 loss, 최선 epoch, 예측·지표, 저장 모델을 제출한다.
- 클래스·사람별 오류와 과적합 양상을 관찰한다. 561특징 MLP를 추가하면 입력이 다른 보조 실험으로 분리한다.

**제출물:** MLP 코드·구조표, 3개 seed 실행 묶음, 학습 곡선, 지표·혼동행렬, 재로딩 기록, 개인 원고.

**작성할 내용:** 기준모델 선정 이유 → 실제 구조 → 학습 조건 → 반복 결과와 오류 → 표현 방식과 모델 규모의 한계.

**완료 기준:** 같은 원자료에서 지표를 재계산하고 저장 모델을 불러와 예측을 확인할 수 있다.

## 5 최승빈 — 1D CNN

- `(N,128,9)`에서 128을 시간축, 9를 채널로 사용한다. Conv1D가 이동하는 축을 코드와 구조표에서 확인한다.
- 필터, 커널, stride, padding, pooling, 출력 집계, 활성화·Dropout, 파라미터 수를 기록한다.
- 층별 시간 길이를 실제로 확인하고 공통 규약의 세 seed 학습·평가를 수행한다.
- 지역적인 시간 패턴을 추출하는 구조적 이유를 설명하되 어떤 패턴을 실제로 학습했는지는 별도 분석 없이 단정하지 않는다.

**제출물:** CNN 코드, 층별 shape·구조표, 3개 seed 실행 묶음, 학습 곡선, 지표·혼동행렬, 재로딩 기록, 개인 원고.

**작성할 내용:** 시간축 합성곱 선정 이유 → 커널·풀링·출력 구성 → 실측 성능 → 오분류·모델 규모·효율의 해석.

**완료 기준:** 입력 축과 출력 차원을 확인하고 공통 평가 코드로 결과를 재현할 수 있다.

## 6 유재윤 — SimpleRNN

- `(N,128,9)`를 길이 128의 시퀀스로 처리한다. LSTM과 구분되는 기본 RNN과 실제 라이브러리 층 이름을 명시한다.
- 은닉 크기, 층 수, 활성화, 마지막 시점 또는 전체 출력 사용, Dropout, 파라미터 수를 기록한다.
- 기본안은 구간마다 독립 상태를 사용하는 stateful=False다. 구간끼리 상태를 이어 쓰면 그 근거와 초기화 규칙을 공유한다.
- 세 seed를 학습·평가하여 수렴 속도, loss 변동, 클래스·사람별 오류를 기록한다. 기울기 소실·폭주는 실제 측정 근거가 있을 때만 발생했다고 쓴다. clipping을 쓰면 값과 적용 모델을 기록한다.

**제출물:** RNN 코드·구조·상태 처리 설명, 3개 seed 실행 묶음, 학습 곡선, 지표·혼동행렬, 재로딩 기록, 개인 원고.

**작성할 내용:** 순차 처리와 은닉 상태 → 구조·상태 초기화 → 학습·성능 관찰 → LSTM과 비교 가능한 차이와 확인하지 못한 원인.

**완료 기준:** 시간축·상태 정책을 설명할 수 있고 반복 결과와 관찰의 근거가 남아 있다.

## 7 이봉헌 — LSTM과 전체 취합

- 같은 `(N,128,9)`의 LSTM을 구현하고 은닉 크기·층 수·출력 집계·Dropout·파라미터 수를 기록한다.
- 입력·망각·출력 게이트와 셀 상태를 기본 RNN과 비교하여 실제 구현과 연결해 설명한다.
- 세 seed를 학습·평가하고 클래스·사람별 오류, 학습 곡선, 재로딩 기록을 작성한다.
- RNN과 같은 은닉 크기라도 파라미터 수가 같지는 않다. 규모 차이가 있으면 순수 게이트 효과만의 비교라고 주장하지 않는다.
- 완료 데이터를 공통 학습 코드에 연결하고 모델 선택 경로를 네 모델에 맞춘다. 각 담당자가 자신의 연결 결과를 확인한다. 기존 MLP 전용 CLI 확장은 별도 구현 작업이며 이 문서 작성으로 완료된 것은 아니다.
- 전원과 설정·선택 규칙을 정리하고 실행 대장을 취합한다. 예측·지표를 같은 평가 코드로 집계하여 통합 비교표를 만든다.
- 개인 원고를 취합해 서론·초록·결론을 작성하고 각 담당자의 사실 확인과 전원 최종 검토를 거쳐 제출본을 만든다.

**제출물:** LSTM 코드·구조표, 3개 seed 실행 묶음, 학습 곡선, 지표·혼동행렬, 재로딩 기록, LSTM 개인 원고, 공통 규약·실행 대장·비교표·논문 통합본.

**작성할 내용:** LSTM 선정 이유·구조 → 실제 조건 → 반복 결과 → RNN 등과의 차이·한계. 전체 결론은 네 모델 결과가 나온 뒤 작성한다.

기존 이봉헌의 MLP 코드·24회 후속 실험·보고서는 이전 작업의 근거로 보존한다. 한윤섭은 이어받아 활용한 범위와 새로 수행한 실험을 구분한다. 과거 MLP 결과를 LSTM 결과로 옮기거나 기존 수행자를 바꾸어 표기하지 않는다.

| 저장·복원 | 모델, 대응 전처리·metadata, 재로딩 명령, 예측 허용오차·최대 차이 |
| 분석·원고 | 곡선·혼동행렬, 오류 sample_id, 수정 가능한 표·그림 원자료, 개인 원고·참고문헌 |

각 담당자는 정상 입력·잘못된 shape·비유한 값 처리와 평가 모드 실행을 확인한다. 혼동행렬은 행=정답, 열=예측으로 통일한다. 사람 ID는 분할·분석에만 쓰고 모델 입력에 넣지 않는다.

추론 시간을 비교하려면 네 저장 모델을 **같은 장치·환경·batch·측정 범위**에서 측정한다. 워밍업·반복 수, 동기화, 전처리 포함 여부를 적고 원자료에서 median·p95를 계산한다. 서로 다른 개인 PC의 측정값을 속도 순위로 사용하지 않는다. 측정 담당·장소는 팀이 정하며 속도는 선택 항목이다.

## 9 공통 실험 계획

### 완료 데이터와 분할

최종 공유 버전의 전처리·분할을 고정한다. 현재 저장소 안내의 기준은 float32 `(N,128,9)`, int64 라벨 `0..5`, 채널 body_acc xyz / body_gyro xyz / total_acc xyz다. 최종 파일의 실제 규격을 데이터 사전과 대조한다.

- 기존 S0: fit 16명 5,577구간, validation 사람 `[1,6,14,21,23]` 5명 1,775구간.
- 공식 test: 9명 2,947구간. 전처리 fit·개발 튜닝·모델 선택에 사용하지 않는다.
- 공통 학습 seed 제안: 2026·2027·2028. 학습 전에 설정하고 분할 생성 seed와 구분한다.

위 수치는 기존 저장소의 기준이다. 완료한 최종 전처리에서 분할이 바뀌었다면 정회서가 전달한 실제 목록을 공동 규약에 기록하고 모두 동일하게 사용한다.

### 기본 12회와 선택 확장

기본안은 **고정 분할 1개 × 네 모델 × seed 3개 = 12회**다. 담당자별 자기 모델의 3회 결과를 제출한다. seed 반복은 고정 분할에서의 학습 변동이며 여러 사람 분할의 안정성을 입증하지 않는다.

추가 사람 분할 S1·S2까지 비교하면 **4 × 3 × 3 = 총 36회**다. 기본 12회에 24회를 추가하는 선택 확장이다. 새 분할은 사전에 정하고 각 fit 사람에 맞춰 통계를 산출한다. 완료된 S0 통계를 그대로 가져와 사람 분할 실험이라고 보고하지 않는다. 추가 처리는 팀 합의 후 수행한다.

### 학습과 모델 선택

연결 점검의 출발값은 기존 trainer의 Adam, batch 64, 최대 40 epoch, val_loss 기준 patience 6 및 최선 가중치 복원이다. 실제 학습률·구조·탐색 예산은 본 실험 전에 정해 training_protocol.md에 적는다. 같은 설정을 썼다는 사실만으로 모든 모델에 최적인 비교라고 주장하지 않는다.

튜닝 시 같은 사전 탐색 예산·선택 규칙을 적용하고 튜닝 run은 별도 집계한다. 불리한 모델에만 추가 탐색하거나 seed를 제외하지 않는다. 실패 run과 변경 사유를 보존한다.

validation은 조기 종료와 설정 선택에 사용하므로 독립 최종 성능 추정치로 표시하지 않는다. test를 쓸 경우 설정·평가 대상을 동결하고 합의한 시점에 평가한다. 기본안은 같은 분할로 학습한 네 모델의 세 seed 전체인 **12개 저장 모델**을 평가하는 것이다. 최고 seed만 고르지 않는다. 공식 train 전체 재학습을 선택하면 epoch 결정과 전처리 재fit 규칙도 test 전에 정한다.

test 결과로 재튜닝하지 않는다. 평가 시점은 기존 수업의 9주차 방침과 팀·지도교수 일정을 맞춰 정한다. 합의 전에는 개발 검증 결과로 작성 범위를 한정한다.

### 집계와 해석

모델별 seed 평균·표본 SD와 같은 분할·seed의 모델 간 차이를 보고한다. SD를 사람 모집단의 신뢰구간으로 표현하지 않는다. 선택 확장의 분할은 사람이 겹칠 수 있으므로 독립 표본으로 간주하지 않는다. 클래스·사람별 support와 오류 예시를 확인한다.

## 10 완료 전처리와 기존 코드의 연결

아래는 커밋 f943e41에서 읽어 확인한 연결 차이다. 전처리를 다시 하라는 목록이 아니며 최종 버전에서 이미 해결한 항목은 근거만 연결한다.

| 항목 | 기존 차이와 인계 기준 |
|---|---|
| 반환 키 | 새 Xs·Xf와 기존 X_seq·X_features를 명시적으로 대응 |
| sample_id | 새 원 행 번호 0 시작과 기존 기록의 1 시작 구분. 실제 원본 행으로 대응 확인 |
| 표준화 상태 | 전달 배열이 표준화 완료인지 확인하고 중복 적용 방지 |
| 전처리 파일 | seq_mean·feat_mean 등과 reference_npz_v1의 키 차이 연결. 모델과 사용 데이터·통계를 함께 보관 |
| PCA | 100차원 고정과 설명분산 95% 기준 구분. 시계열 비교의 사용 여부 명시 |
| test | 로딩과 성능 평가·튜닝 사용을 구분하여 기록 |
| 전달 위치 | 과거 커밋 목록과 별개로 완료된 전체 파일의 현재 공유 위치·버전·생성 명령 기록 |

정회서는 데이터 규격·출처를 설명하고 각 모델 담당자는 자신의 연결 결과를 확인한다. 기존 MLP 점수는 전처리·분할·설정의 대응 확인 없이 새 비교표에 합치지 않는다.

## 11 개인 원고 작성과 제출

각자 공통 양식에 **5~8개 문단**으로 초안을 작성한다. 내부 취합용이며 최종 학회 논문은 팀 전체를 합쳐 1~2쪽이다.

1. 담당 목적과 공동 연구 질문과의 관계.
2. 실제 방법·구조와 선택 이유.
3. 데이터·분할·설정·seed·환경.
4. 실제 결과와 run_id·원자료 경로.
5. 해석과 적용 범위·한계.
6. 실제 문제의 재현·원인·수정·재검증 또는 정상 동작 확인.
7. 참고문헌, 본인 수행 범위, 팀원에게 받은 자료, 남은 작업.

실제 오류와 의도적 대조를 구분하며 없었던 문제를 만들지 않는다. 미실행 결과는 `[측정 예정]`으로 표시한다. 표·그림에 제목·축·단위·비교 조건·원자료를 붙이고 수정 가능한 자료를 제출한다. AI 보조는 검토 범위를 적고 제출처 표기 기준을 확인한다.

| 담당 | 작성할 양식 | 권장 제출 폴더 |

| 정회서 | [데이터 원고](templates/01_data_contribution.md) | contributions/01_data/ |
| 한윤섭 | [MLP 원고](templates/02_mlp_contribution.md) | contributions/02_mlp/ |

각 폴더에는 contribution.md, 주장·근거를 대응시킨 evidence_index.md, references.md, 그림·원자료, 실행 안내를 둔다. contributions는 제안 경로이며 생성 완료를 뜻하지 않는다. 큰 데이터·모델은 보관 경로와 버전을 적는다.

## 12 한 편으로 취합

| 논문 부분 | 제공자와 취합 |
|---|---|

| 데이터·전처리 | 정회서 |

개인 보고서를 이어 붙이지 않고 하나의 질문에 답하도록 편집한다. 모델명·지표 자릿수·조건·그림 번호·용어를 통일한다. 각자 사실·수치를 검증하고 전원은 전체 주장·저자·소속·제출 파일을 확인한다. 저자 순서·교신저자·발표자는 실제 기여와 팀·지도교수 협의로 정한다.
