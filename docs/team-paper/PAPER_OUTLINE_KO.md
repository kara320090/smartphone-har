## 1 서론

담당 취합: 이봉헌. 전원이 각자의 관련 원문 자료를 제공한다.

- 스마트폰 센서 행동 인식의 문제와 이번 평가 목적을 짧게 설명한다.
- 단순 모델 나열에 그치지 않도록 비교하려는 질문을 명시한다.
- 기존 HAR의 모델 비교·사람별 일반화 연구와 이번 분석의 범위를 설명한다.
- 새로운 알고리즘이나 최초 발견을 근거 없이 주장하지 않는다.

## 2 자료와 방법

정회서의 자료·전처리 원고와 이봉헌·유재윤의 모델·학습 원고를 결합한다.

필수 항목: 입력 128×9, 클래스 정의, 사람 단위 분할, fit-only 표준화, 모델 구조, 학습·선택 규칙, 반복 seed, 구현 버전. 특징 MLP를 넣으면 입력 표현이 다른 보조 비교임을 표시한다.

표 1 후보: 세 모델의 구조 요약, 파라미터 수, 공통 입력. 실제 모델 생성 결과로 채운다.
