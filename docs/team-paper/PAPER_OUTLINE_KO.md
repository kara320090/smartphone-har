# 공동 논문 취합 골격

상태: 전처리 완료를 반영한 골격. 네 모델의 공동 비교 결과와 저자 정보는 아직 채우지 않았다. 취합 내용을 대학생 전용 공식 양식으로 옮긴다.

## 제목

스마트폰 센서 기반 MLP·CNN·RNN·LSTM의 사용자 독립 행동 인식 성능 비교

저자·소속·교신저자: [실제 기여와 팀·지도교수 협의 후 기입]

## 초록

본 연구는 UCI HAR의 동일한 센서 구간과 사람 분할을 사용하여 MLP, 1D CNN, SimpleRNN, LSTM의 행동 분류 성능을 비교한다. [실제 수행한 분할·반복 횟수]에서 [지표]와 [측정 범위]를 분석하였다. [핵심 실측 결과와 수치]. 결과는 [확인한 결론]을 보여주며, [데이터·평가 범위의 한계]를 갖는다.

초록은 결과 확정 후 작성한다. 전처리 완료와 모델 비교 완료를 구분한다.

## 1 서론

이봉헌 취합, 전원 관련 원문 자료 제공. 스마트폰 센서 행동 인식의 문제와 사용자 독립 평가 목적을 설명한다. 같은 입력에서 벡터 처리·합성곱·기본 순환 구조·LSTM을 비교하는 질문과 기존 연구 대비 범위를 명시한다. 모델 수만으로 새로운 알고리즘이나 최초 발견을 주장하지 않는다.

## 2 자료와 방법

| 부분 | 제공자 | 필요한 내용 |
|---|---|---|
| 데이터·전처리 | 정회서 | 최종 버전, 128×9 입력·채널·클래스, 사람 분할, 통계 fit 범위 |
| MLP | 한윤섭 | 펼치기, 은닉층·활성화·출력, 파라미터 수 |

| SimpleRNN | 유재윤 | 은닉 크기·상태 초기화·출력, 파라미터 수 |
| LSTM | 이봉헌 | 셀·게이트 구조, 은닉 크기·출력, 파라미터 수 |
| 공통 학습 | 네 담당자 확인, 이봉헌 취합 | seed, optimizer·설정, 선택 규칙, 실제 반복 수, 버전 |

표 1 후보는 네 모델의 구조·파라미터 수다. 특징 MLP를 추가하면 별도 입력의 보조 실험으로 표시한다.

클래스·사람별 오류와 곡선에서 핵심 관찰을 고른다. 낮은 RNN 점수만으로 기울기 소실을 단정하거나 높은 LSTM 점수만으로 장기 의존성 학습을 증명했다고 쓰지 않는다. 규모가 다르면 구조만의 효과로 단정하지 않는다. 시간 비교는 동일 장치·환경·batch·범위에서 측정한 값만 사용한다.

## 4 결론

이봉헌 초안, 전원 검토. 실측한 차이와 데이터·분할·반복 수·튜닝 범위의 한계를 적는다. 최고 모델을 미리 정하지 않는다. 추가 분할을 실행하지 않았다면 분할 간 안정성을 검증했다고 쓰지 않는다.
