# 유재윤 RNN 개인 기여 원고

본 연구에서 기본 순환신경망을 128×9 센서 구간의 순차 처리 기준으로 사용하였다. Keras SimpleRNN은 현재 입력과 직전 은닉 상태를 tanh로 결합하며 각 구간 시작에서 상태를 0으로 초기화하였다. 마지막 은닉 상태를 Dense 6으로 변환해 여섯 행동의 로짓을 출력하였다. 기준 R01은 은닉 32개와 총 1,542개 파라미터를 갖는다.

제공된 팀 캐시의 시계열은 표준화 전 배열이므로 학습 16명 5,577개에서 계산된 저장 통계를 한 번 적용하였다. 검증은 피험자 1·6·14·21·23의 1,775개 구간으로 고정하였다. 사람 ID는 분할과 오류 분석에만 사용하였고 원본 표본 ID와 0–5 라벨 순서를 유지하였다.

Adam 학습률 0.001, 배치 64, 최대 40에포크, 검증 손실 기준 patience 6과 최선 가중치 복원을 적용하였다. seed 2026·2027·2028을 각각 모델 생성 전에 설정하였다. 교차엔트로피 손실을 사용하고 구간 간 상태 유지와 기울기 clipping은 적용하지 않았다.

기준 R01의 검증 Macro F1은 0.7191 ± 0.0586, 정확도 평균은 0.7356이었다. 은닉 64의 R02와 출력 Dropout 0.3의 R03을 튜닝 후보로 실행하였다. R03은 같은 seed R02의 학습 전 가중치를 복사하여 비교하였다. 표준편차는 고정 분할에서 세 학습 seed의 표본 표준편차이다.

세 seed 검증 Macro F1 평균으로 R02를 선택하였으며 평균 0.7715 ± 0.0675, 정확도 평균 0.7855를 확인하였다. R02의 Macro F1 평균은 R01보다 약 5.24%p 높았다. 튜닝 선택 결과는 기준 R01의 팀 비교 행과 구분하였고, 모든 seed를 보존하였다. 검증셋은 조기 종료와 선택에 사용했으므로 이 개선을 독립 최종 일반화 성능으로 표현하지 않았다.

작은 RNN의 30개 파라미터 중심차분을 자동미분과 대조하여 최대 절대 오차 1.875e-11을 확인하였다. 상태 초기화와 입력 계약, 저장 모델의 검증 전체 재로딩 및 지표 재계산을 확인하였다. 선택 조건 seed 2026의 가장 큰 오분류는 걷기에서 계단 오르기로의 143개였다. 같은 사람·같은 정답의 오류와 성공 파형을 3쌍 대조하였다. 초기 고정 배치 기울기 진단은 시점별 기울기 소실을 증명하지 않는다.

이번 결과는 개발 검증 결과이며 공식 test는 미평가이다. 검증셋을 조기 종료와 후보 선택에 사용했으므로 독립 최종 평가가 필요하다. 최종 평가 대상과 팀 전체 모델 비교 조건을 고정한 뒤 공식 test를 평가해야 한다.
