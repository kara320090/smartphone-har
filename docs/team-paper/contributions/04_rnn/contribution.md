# 유재윤 RNN 개인 원고

작성일 2026년 10월 12일 · RNN 구현 학습 평가 · 팀 내부 취합용

본 연구에서 기본 순환신경망은 동일한 128×9 센서 구간의 순차 처리 기준으로 사용하였다. Keras SimpleRNN[2]의 은닉 상태는 현재 입력과 직전 상태를 tanh로 결합하며 각 구간 시작에서 0으로 초기화하였다. 마지막 시점의 은닉 상태를 Dense 6으로 변환해 여섯 행동의 logits를 출력하였다. 기준 R01은 은닉 32개와 총 1,542개 파라미터를 갖는다.

UCI HAR[1]를 바탕으로 제공된 팀 캐시의 시계열은 표준화 전 배열이므로 학습 16명 5,577개에서 계산된 저장 통계를 한 번 적용하였다. 검증은 피험자 1·6·14·21·23의 1,775개 구간으로 고정하였다. 사람 ID는 분할과 오류 분석에만 사용하였다. 라벨은 0–5이며 원본 sample_id를 유지하였다.

Adam 학습률 0.001, batch 64, 최대 40 epoch, validation loss 기준 patience 6과 최선 가중치 복원[3]을 적용하였다. seed 2026·2027·2028을 각각 모델 생성 전에 설정하였다. 출력은 logits이며 교차엔트로피 손실을 사용하였다. 구간 사이 상태를 이어 쓰거나 clipping을 적용하지 않았다.

기준 R01의 validation Macro F1은 0.7191 ± 0.0586, Accuracy 평균은 0.7356였다. SD는 고정 분할에서 세 학습 seed의 표본 SD다. 은닉 64 R02와 출력 Dropout 0.3 R03을 별도 튜닝 조건으로 실행했고 세 seed 평균 기준으로 R02를 선택하였다. R03은 R02의 같은 seed 학습 전 가중치를 복사하여 비교하였다. 튜닝 결과를 기준 R01의 공동 비교 결과와 구분하였다.

같은 제공 데이터와 평가 코드로 MLP·계획서 CNN·main LSTM을 보조 재실행하였다. 네 모델의 파라미터 규모와 출력 집계가 달라 성능 차이를 순환 구조 하나의 효과로 단정하지 않았다. 이 재실행은 RNN 담당 작업의 비교 자료이며 다른 담당자의 수행 실적으로 기재하지 않는다.

작은 RNN의 중심차분 30개를 자동미분과 대조했고 최대 절대 오차 1.875e-11을 확인하였다. 잘못된 입력 거부, 구간 상태 초기화, 저장 모델의 validation 전체 재로딩과 지표 재계산도 확인하였다. 선택 조건 seed 2026의 가장 큰 오분류는 걷기에서 계단 오르기로의 143개였다. 초기 고정 배치의 기울기 norm은 수치 검증이며 장기 기억 또는 시점별 소실을 증명하지 않는다.

이번 결과는 개발 validation 결과이며 공식 test는 미평가다. 최종 평가 시점·대상은 팀 합의 후 고정해야 한다. 데이터·공통 코드는 팀에서 제공받았고 RNN 코드·실험·분석·원고는 Codex 보조로 생성하였다. 최종 제출 전에 담당자의 코드·수치·설명 검토가 필요하다. 근거는 docs/rnn-report/REPORT_KO.md, reports/rnn/, runs/rnn/에 보관하였다.
