# 공동 논문 1~2쪽 편집 기준

제한은 **팀 전체 논문의 제목·저자·본문·그림·표·참고문헌 합계 1~2쪽**이다. 담당자마다 1~2쪽씩 쓰는 기준이 아니다. 기존 2쪽 HWP는 상세한 LSTM 검토 초안이므로 팀 결과를 모두 넣을 최종본에서는 이 묶음의 압축 원고를 우선 사용한다.

## 최종 2쪽의 구성 제안

| 묶을 내용 | 담당·편집 기준 | 지면 배분의 출발점 |
| --- | --- | ---: |
| 제목·저자·소속·지도교수 | 확정 후 한 번만 표기 | 약 10% |
| 연구 배경과 비교 질문 | 팀 공통, 약 250~350자 | 약 10% |
| 데이터·분할·전처리·실험 조건 | 정회서 설명과 실제 모델 설정을 합침 | 약 20% |
| 네 모델의 방법 | 모델별 약 120~200자, 실제 구조·차이 중심 | 약 20% |
| 핵심 그림 | 1개를 우선 선택, 필요하면 전체 모델 도식으로 취합 | 약 10% |
| 통합 비교표 | 4개 모델 각 1행, 같은 반복·지표 단위 | 약 10% |
| 결과 해석·한계·결론 | 실제 취합 결과에 근거, 약 250~350자 | 약 10% |
| 참고문헌 | 중복 제거, 핵심 문헌 약 4~6개 | 약 10% |

이는 편집을 시작하기 위한 제안이다. 저자란 길이·문헌 길이·그림 수에 따라 실제 배분이 달라지므로 공식 양식에 취합한 뒤 전체 페이지를 렌더링해 확인한다. 글꼴을 과도하게 줄여 맞추지 않는다.

## 봉헌 담당 자료를 넣는 방법

1. `LSTM_논문삽입용_본문그림.hwp`의 모델 문단을 모델 설명 절에 넣는다. 현재 약 222자 본문 중 방법과 결과를 각각 필요한 절에 배치한다.
2. 구조 그림은 가로 **80 mm**, 세로 약 **28.6 mm**다. 공식 학생 양식의 본문 한 단에 들어가는 크기로 만들었다. 그림 아래의 제목은 일반 문단으로 쓰고 ‘글자처럼 취급’을 유지한다. 그림 번호는 전체 취합 순서에 맞춰 바꾼다.
3. 그림을 하나만 넣기로 한다면 이 LSTM 구조 그림이나 실제로 확인된 네 모델의 통합 구조 그림 중 연구 질문에 더 맞는 것을 선택한다. 팀 전체 도식에 통합할 때 LSTM 가지는 이 그림의 구조를 그대로 사용한다. 아직 확인하지 않은 다른 모델 구조를 그림에 확정된 것처럼 그리지 않는다.
4. `LSTM_COMPARISON_ROW.csv`를 통합 결과표의 LSTM 한 행으로 사용한다. 별도 LSTM 결과표·seed별 표를 다시 넣지 않는다.
5. 학습 설정은 `LSTM_COMPACT_INSERT_KO.md`의 설정 포함 문단에서 가져온다. 다른 모델의 실제 설정을 확인한 뒤 공통 부분은 한 번만 적고 차이는 표나 짧은 문장으로 남긴다.
6. validation은 epoch 선택에도 사용한 개발 자료다. 공동 실험 절과 한계에서 이 사실을 한 번 명시한다. 최종 test 성능처럼 쓰거나 ‘미지 사용자 전반에서 일반화가 입증되었다’고 표현하지 않는다.

## 팀원별로 지금 받을 내용

| 담당 | 필요한 원고와 근거 |
| --- | --- |
| 정회서 | 데이터 출처, 채널·라벨, 사람 분할, 표준화 통계의 산출 범위, 실제 데이터 버전 |
| 한윤섭 MLP | 실제 입력 표현과 층 크기, 파라미터 수, 학습 조건, 세 seed 예측·지표, 약 120~200자 방법 문단 |
| 최승빈 CNN | 실제 시간축 커널·필터·풀링·분류기, 파라미터 수, 조건과 세 seed 결과, 약 120~200자 방법 문단 |
| 유재윤 RNN | 실제 RNN 종류·유닛 수·상태 처리·분류기, 파라미터 수, 조건과 세 seed 결과, 약 120~200자 방법 문단 |
| 이봉헌 LSTM | 압축 본문, 확인된 L01 구조 그림, L01 세 seed 결과 한 행, 보조 근거 위치 |

각자의 표·그림을 전부 본문에 넣기보다 실제 근거를 받은 뒤 하나의 공통 그림과 비교표로 합친다. 팀원 이름의 위 나열 순서는 역할표이며 논문의 저자 순서가 아니다.

## 상세 보고서와 발표에 남길 내용

게이트 수식의 전체 유도, 순전파·시간축 역전파 검산, 의도적 미분 오류 주입, 데이터 연결 오류 탐지, 저장 모델 검증 허용 오차, L02·L03 보조 실험, 학습 곡선·혼동행렬·사람별 오류·CPU 추론 시간은 개인 상세 보고서와 수업 발표·부록에서 설명한다. 공동 학술 논문에는 연구 질문과 비교 결과를 이해하는 데 필요한 내용만 선택한다.

최종 원고의 비교·초록·결론·저자는 팀원 결과와 지도교수 검토 후 확정한다. 대학생 양식에는 별도 초록 예시가 없으므로 원고 앞부분의 요약 방식은 실제 공식 양식과 지도교수 검토를 따른다. 현재 개인 기여 파일을 독립 논문으로 제출하지 않는다.
