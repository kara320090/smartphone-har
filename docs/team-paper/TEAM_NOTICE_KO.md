# 팀 공동 논문 준비 공지 — 최신 역할 반영

역할은 **데이터 정회서 / MLP 한윤섭 / CNN 최승빈 / RNN 유재윤 / LSTM 이봉헌**으로 진행합니다. **전처리는 완료되었으므로**, 같은 전처리 결과와 사람 분할을 사용해 네 모델을 비교하는 공동 논문 1편을 준비하겠습니다.

| 담당 | 진행할 내용 | 제출할 결과물·원고 |
|---|---|---|
| 정회서 | 완료한 데이터·전처리 인계와 방법 설명 | 최종 파일 위치·버전, 데이터 규격·분할·통계, 데이터 및 전처리 원고 |
| 한윤섭 | MLP 구현·학습·평가 | 모델 코드·구조표, 학습·평가 결과, MLP 방법·결과·한계 원고 |
| 최승빈 | 1D CNN 구현·학습·평가 | 모델 코드·구조표, 학습·평가 결과, CNN 방법·결과·한계 원고 |
| 유재윤 | SimpleRNN 구현·학습·평가 | 모델 코드·구조표, 학습·평가 결과, RNN 방법·결과·한계 원고 |
| 이봉헌 | LSTM 구현·학습·평가 및 전체 취합 | LSTM 결과·원고, 공통 규약·비교표, 최종 통합 원고 |

모델 담당자 네 명은 **같은 데이터·분할·평가 기준**으로 각자 코드, 설정, 저장 모델, 예측·지표, 학습 곡선, 혼동행렬, 재로딩 기록을 제출해 주세요. 기본 실험안은 모델별 seed 3개씩 **총 12회**입니다. 추가 사람 분할 실험은 일정과 자원을 확인한 뒤 함께 결정하겠습니다.

개인 원고는 **목적 → 실제 방법 → 실험 조건 → 결과 → 해석과 한계** 순서로 5~8개 문단 정도 작성해 주세요. 실제 문제가 있다면 재현·원인·수정·재검증을 적고, 수치에는 실행 ID와 근거 파일을 연결해 주세요. 미실행 내용은 계획으로 표시하고 표·그림 원자료도 함께 제출해 주세요.

제가 맡은 LSTM 내용까지 포함해 원고를 취합하고, 각자 담당 내용·수치를 확인한 뒤 전원이 최종 검토하여 **하나의 공동 논문으로 제출**하겠습니다. 최종 학회 논문은 전체 1~2쪽이므로 상세 개인 원고와 근거를 바탕으로 핵심 내용을 편집하겠습니다.

교수님 안내에 따라 같은 프로젝트로 수업 발표와 공동 논문·학술 발표를 준비합니다. 수업에서는 각자 모델의 원리·구현·검증·시행착오를 설명하고, 논문에는 같은 조건에서 확인한 팀 전체 결과를 취합합니다. 수치와 역할 표기는 동일하게 유지합니다. LSTM 9회 실행은 완료됐고 공동 비교에는 L01 세 seed를 사용합니다. MLP·CNN·RNN의 실제 결과는 담당자 자료를 받은 뒤 채웁니다.
