# 팀 공동 논문 준비 공지

기존 스마트폰 행동 인식 프로젝트를 발전시켜, **MLP·1D CNN·LSTM의 사용자 독립 성능과 안정성을 비교하는 공동 논문 1편**을 준비하려고 합니다. 기존 UCI HAR 데이터를 그대로 사용하고, 동일한 센서 구간·사람 분할·평가 기준으로 비교할 계획입니다.

각자 맡은 작업을 진행하면서 **코드와 결과물뿐 아니라, 본인이 실제로 수행한 내용을 논문 문장으로 작성해서 함께 제출**해 주세요. 제가 맡은 MLP·공통 학습 내용까지 포함해 전체 원고를 취합하고, 전원이 검토한 뒤 하나의 논문으로 제출하겠습니다.

| 담당 | 해야 할 작업 | 제출할 결과물과 원고 |
|---|---|---|
| 정회서 | 데이터 로딩·분석, 사람별 분할, 학습 자료만 사용한 전처리 | 데이터 사전·분할 목록·통계·분포표와 데이터 및 전처리 설명 |
| 이봉헌 | MLP, 공통 학습 코드, 재현성 검증, 진행 관리와 논문 취합 | 기준모델·공통 설정·학습 결과·검증 기록과 방법론 원고, 전체 통합본 |
| 유재윤 | 1D CNN·LSTM 구현, 구조 비교, 공통 학습 연결 | 모델 코드·구조표·실행 묶음과 모델 선정 이유 및 구조 설명 |
| 한윤섭 | 공통 실험 설계, 반복 실행 관리, F1·혼동행렬·사람별 분석 | 비교표·그래프·예측 근거와 실험 결과 및 한계 원고 |
| 최승빈 | 공통 추론, 모델 재로딩, 입력 오류 처리, 같은 장치에서 시간 측정 | 추론 코드·검증 기록·시간 원자료·시연과 효율성 및 통합 검증 원고 |

원고는 각자 **목적 → 실제 방법 → 실험 조건 → 결과 → 해석과 한계** 순으로 5~8개 문단 정도 작성하면 됩니다. 수치는 원자료와 실행 ID를 연결하고, 표·그림은 수정 가능한 자료도 같이 제출해 주세요. 실제 문제가 있었다면 원인·수정·재검증을 적고, 미실행 내용은 계획으로 구분해 주세요.

최종 학회 논문은 팀 전체 내용을 취합한 **1~2쪽**입니다. 개인별 원고 분량을 그대로 이어 붙이는 방식이 아니라, 공통 연구 질문에 필요한 내용을 제가 편집하고 각자 사실과 수치를 확인하는 방식으로 진행하겠습니다. 세 모델의 핵심 비교를 먼저 완성하고 PCA·군집·RNN·AE 등 기존 수업 작업은 별도로 보존하겠습니다.

내부 일정은 **10월 11일 규약 확정, 14일 연결 검사, 17일 기본 결과, 20일 개인 원고와 근거 1차 제출, 24일 통합본, 25일 전원 검토**를 제안합니다. 공식 논문 마감은 **10월 26일**입니다. 가능 일정과 의존 작업은 먼저 공유해 주세요. 저자 순서·교신저자·발표자와 최종 test 사용 시점은 팀 및 지도교수와 협의해 정하겠습니다.
