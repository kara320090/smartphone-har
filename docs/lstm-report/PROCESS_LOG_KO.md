# LSTM 구현과 실험 과정

## 사전 계획

승인받은 L01·L02·L03과 seed 2026·2027·2028을 고정했다. 정식 학습 코드 커밋은 `95422e0993935be59db21248742f83c5fdf5453d`다. 공식 test 평가와 다른 팀원 모델 구현은 포함하지 않았다.

## 실제 연결 차이

1. 캐시가 분할된 배열이고 표준화 통계는 별도임을 소스·통계 대조로 확인했다. 저장 통계를 한 번 적용했다.
2. 기존 reference_npz_v1과 팀 통계 파일의 키가 달라 전용 저장·복원 경로를 추가했다. 기존 형식은 유지했다.
3. 기존 1 기반 ID와 팀 0 기반 ID를 구분했다. 원본 train의 7,352개 구간·9채널·정답·사람을 모두 대조했다.
4. float64 참조 경로와 float32 팀 경로의 검증 입력 최대 차이는 0.00685120였다. 통계를 임의로 바꾸지 않고 이번 입력을 고정했다.

이는 연결 규약의 차이와 해소 과정이며 이미 발생한 데이터 누출이나 학습 성능 사고를 재현한 기록이 아니다.

## 검증 과정

기존 MLP와 새 LSTM 테스트 39개가 통과했다. 작은 세 조건 연결 실험은 정식 9회와 별개다. LSTM 수학 예제는 58개 파라미터에 대해 174회 중앙차분을 확인했다. 망각 게이트 미분을 일부러 생략한 음성 대조에서 차이를 탐지했으며 이를 실제 Keras 결함으로 표현하지 않았다.

## 정식 실행

9회 모두 같은 fit·validation과 학습 설정을 사용했다. L03은 같은 seed L01의 학습 전 가중치를 복사했다. 새 프로세스의 전체 1,775개 재예측과 저장 예측 CSV의 지표 재계산을 확인했다. 실패한 정식 실행을 성공으로 바꾸거나 불리한 seed를 제외하지 않았다.

L01 Macro F1 평균은 0.8813, 표본 SD는 0.0195다. L02·L03 평균은 0.8911, 0.8550다. 자세한 실행 epoch와 값은 `reports/lstm/runs.csv`에 있다.

## 범위와 후속 작업

작업 중 정식 모델의 유한성 실패는 완료된 로그에서 관찰되지 않았다. 로그가 뒷받침하지 않는 실패·복구 이야기를 추가하지 않는다. 최종 test, 팀원 모델의 같은 조건 비교, 다양한 사람·장치 검증은 후속 공동 작업이다. 문서 작성 등 다른 작업을 학습 중 병행했으므로 학습 시간은 정밀한 효율 순위보다 실행 비용 기록으로 해석한다.
