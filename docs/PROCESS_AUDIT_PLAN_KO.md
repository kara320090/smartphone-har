# 과정 심화 검증 계획

이 계획은 과정 보강 요청에 따라 새 검증을 실행하기 전에 작성했다. 기존 7개 실험의 사전 가설 문서로 소급하여 주장하지 않는다.

## 수정 전 재현과 수정 범위

현재 기준 커밋은 `7aec3ace542c8d915abae83b462531dc9a68cdf4`이다. 실제 UCI 자료는 정상 정수 분할을 사용했다. 다음 결함은 외부 모듈과 연결할 때 잘못된 입력을 탐지하지 못할 가능성에 관한 것이며 기존 UCI 결과가 오염되었다고 미리 결론 내리지 않는다.

1. 소수·음수 분할 인덱스가 조용히 다른 행을 선택하는지 재현한다.
2. 저장용 원본 검증 자료의 행 순서가 변해도 입력 계약 검사를 통과하는지 재현한다.
3. 수정 전후 같은 입력을 넣고 정상 입력은 유지하면서 잘못된 입력을 명확한 오류로 거부하는지 확인한다.

## 실험 조건 보강

- 대상은 기존 E02, E03, E07, E08, E09, E10, E11의 7조건이다.
- seed는 실행 전에 2026, 2027, 2028로 고정한다. 결과에 따라 seed를 추가·제외하지 않는다.
- 동일한 5명 검증 분할, 학습 자료만 fit하는 전처리, 기존 epoch·조기 종료 설정을 사용한다.
- 7조건 × 3seed = 21회를 새 프로세스에서 학습한다.
- seed 2026의 검증 예측을 기존 결과와 비교하여 계약 보강이 정상 학습의 수치를 바꾸었는지 확인한다.
- Accuracy와 Macro F1의 평균·표본 표준편차(ddof=1), seed별 차이, E02의 사람별 성능을 보고한다.
- 3seed는 초기화·셔플 변동을 관찰하는 수준이다. 유의성 검정, 모집단 신뢰구간, 다른 사람 분할의 강건성을 주장하지 않는다.
- 공식 test는 읽거나 평가하지 않는다. 검증 자료로 조건을 비교한 데 따른 선택 편향은 한계에 명시한다.

## 설명용 대조 실험

의도적으로 만든 잘못된 구현·입력을 별도 표시한다. 실제 개발 중 우연히 발생한 문제로 서술하지 않는다. 안정적 softmax, ReLU의 비미분점, 배치 평균 미분의 누락, 전처리 누출을 검출하는 대조 실험을 통해 방어 장치가 어떤 오류를 잡고 무엇을 보장하지 않는지 설명한다.
