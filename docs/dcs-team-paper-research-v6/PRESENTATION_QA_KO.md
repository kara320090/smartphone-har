# 발표 핵심과 심사 질의응답

원고 v6 · 스마트폰 행동 인식 신경망의 성능·규모 절충과 피험자별 편차 분석 · 발표자 이봉헌

이 자료는 새 논문에 맞춘 요약 원고다. 기존 인공지능공학 수업용 상세 보고서·PPT의 수학 검증과 구현 과정을 대체하지 않는다. 포스터 발표의 실제 시간·세션은 확정 후 조정한다.

## 90초 설명 원고

“저희는 스마트폰 행동 인식 모델을 고를 때 전체 평균 점수만 보면 놓칠 수 있는 차이를 분석했습니다. UCI HAR의 제공 시계열을 사용해 학습 16명과 검증 5명을 분리하고, MLP·CNN·RNN·LSTM의 기준 구성을 같은 입력과 학습 조건에서 세 seed씩 학습했습니다.

평균 Macro F1은 CNN이 0.8889, LSTM이 0.8813였습니다. 차이는 0.0076였지만 LSTM 파라미터는 75.2% 적었습니다. 그림을 보면 CNN과 LSTM의 평균 순위가 동적 행동과 정적 자세에서 바뀌었고, 피험자 14는 네 구성 모두에서 가장 낮은 성능을 보였습니다. 또한 학습은 그대로 두고 검증 피험자를 한 명씩 제외하는 다섯 진단을 모두 계산했습니다. 14 제외 시 CNN 0.9290, LSTM 0.9334로 평균 순위가 바뀌었습니다. 제외 점수는 개선 성능이 아니라 집단 구성에 따른 민감도를 보는 진단입니다. 대표 결과에는 전체 다섯 명을 그대로 포함합니다.

이 결과는 평균 성능·모델 규모·오류 위치를 함께 보아야 한다는 근거입니다. 다만 개발 검증으로 모델 epoch도 선택했으며 공식 test는 평가하지 않았습니다. 새로운 최적 알고리즘을 제안한 것이 아니라, 고정 네 구성에서 관찰한 절충과 편차를 재현 가능하게 제시한 탐색적 비교 연구입니다.”

## 그림과 표를 설명하는 순서

1. 그림 1: 같은 128×9 입력에서 각 기준 모델의 분류 구조를 설명한다. CNN의 Pool·Dropout, 순환 모델의 마지막 상태와 구간별 0 초기화를 짚는다.
2. 표 1·그림 2(a): CNN-LSTM 평균 F1 차이 0.0076과 파라미터 75.2% 감소를 함께 설명한다. 가로축은 로그 축이고 오차막대는 seed 표본 SD다.
3. 그림 2(b): 피험자 내부 6클래스 Macro F1이다. n은 매 seed의 구간 수이며 14번은 323구간이다. 평균 결과만으로 사용자별 취약성을 판단할 수 없음을 설명한다.
4. 그림 2(c): 양수는 CNN, 음수는 LSTM 평균이 높다는 뜻이다. 전체 5명을 유지한 대표 결과와 재학습 없는 다섯 제외 진단을 구분한다.
5. 행동군 결과: 전체 6클래스 F1을 동적·정적 각 세 클래스로 평균했다. 별도 3클래스 모델이 아니다.
6. 한계: 개발 평가·단일 분할·구성 차이·미측정 오류 원인과 실제 기기 효율을 설명한다.

## 예상 질의응답

**Q1. 이미 CNN·LSTM 논문이 있는데 무엇이 기여인가?**

신경망 종류 자체의 신규성을 주장하지 않는다. 이 팀의 동일 입력·사람 분할과 고정 네 구성에서 성능·규모를 비교하고, 행동군의 평균 순위 변화·공통 취약 피험자·자세 오류 변동을 함께 제시했다. 데이터·모델·예측 근거를 공개해 해석을 검토할 수 있게 했다.

**Q2. CNN과 LSTM 성능이 같다고 봐도 되는가?**

아니다. 평균 차이는 0.0076이며 세 seed의 SD는 초기화 등에 따른 변동을 요약한다. 이 설계로 통계적 동등성이나 비열등성을 검정하지 않았다. 성능 차이와 규모 차이를 함께 관찰한 결과다.

**Q3. 왜 LSTM의 더 좋은 소형 모델 결과를 표에 쓰지 않았는가?**

공동 비교에 정한 대표는 L01이다. L02·L03은 봉헌 담당 심화 분석으로 분리했고 점수가 높다는 이유로 대표를 교체하지 않았다. RNN 개인 튜닝 R02도 기준 R01과 구분했다.

**Q4. 이것은 test 성능인가?**

아니다. 공식 학습 자료 안에서 사람 단위로 만든 개발 validation이며 epoch 선택에도 사용했다. 공식 test는 미평가다. 원논문의 공식 test 점수나 다른 분할의 문헌 점수와 직접 비교하지 않는다.

**Q5. 중첩 윈도우가 분할 사이에 들어가 누출되지는 않았는가?**

제공 신호의 50% 중첩은 유지했지만 사람 단위로 학습·검증을 분리했다. 사람·표본 ID 비중복과 모델 간 ID·정답·데이터 해시 일치를 검사했고 표준화 통계는 학습 자료에서만 구했다. 이 검사 사실을 모든 형태의 누출이 절대 불가능하다는 주장으로 확대하지 않는다.

**Q6. 입력은 561개 특징인가, 센서 원시 신호인가?**

둘을 구분한다. 이번은 제공된 128×9 시계열이며 body_acc xyz, body_gyro xyz, total_acc xyz 순이다. UCI 제공 신호에 이미 필터링·구간화가 적용되어 있어 완전한 원시 신호로 부르지 않는다. MLP는 같은 입력을 1,152차원으로 펼쳤다. PCA는 적용하지 않았다.

**Q7. 모든 학습 조건이 같으면 공정한 구조 비교인가?**

입력·분할·지표·학습률·batch·epoch 상한·중단 규칙·세 seed는 맞췄다. 그러나 은닉 크기·파라미터·헤드·Dropout·개인 탐색 예산은 다르다. 동일 용량·동일 탐색 예산의 순수 구조 효과 비교라고 주장하지 않는다.

**Q8. 동일 seed라면 모델들의 초기 가중치도 동일한가?**

구조와 가중치 shape가 다르므로 동일하다고 말할 수 없다. 같은 seed는 반복 조건의 표기다. LSTM 내부 L01-L03 실험의 학습 전 가중치 복사는 별도 확인된 통제 조건이며, 네 구조 전체를 같은 가중치로 시작했다는 뜻이 아니다.

**Q9. RNN이 낮은 이유가 기울기 소실이라고 입증했는가?**

입증하지 않았다. 게이트·기울기나 원인을 이번 비교에서 측정하지 않았고 용량과 헤드도 다르다. RNN의 동적 평균 0.5711와 정적 평균 0.8671가 다르다는 관찰을 설명한다.

**Q10. 피험자 14가 낮은 이유는 무엇인가?**

네 구성에서 공통으로 낮았다는 사실만 확인했다. 체형·휴대폰 위치·행동 방식 등 원인을 측정하지 않았으므로 단정하지 않는다. LSTM은 전체 0.8813, 이 피험자에서는 0.6089다. 복수 분할과 별도 사용자 평가가 다음 과제다.

**Q11. 앉기·서기 혼동은 새 발견인가?**

아니다. Anguita 등의 원논문에도 보고되어 있다. 이번에는 조건부 오류의 분모와 seed 변동을 명시했다. LSTM 평균 31.3%와 SD 19.6%p를 함께 보아 평균만으로 안정성 개선을 주장하지 않는다.

**Q12. 75.2% 작으면 스마트폰에서 더 빠르고 배터리를 덜 쓰는가?**

이번 근거는 학습 가능한 파라미터 수다. 실제 연산량·메모리·CPU/GPU 최적화·기기 지연·전력을 직접 측정해야 한다. 서로 다른 팀원 PC의 시간으로 속도 순위를 정하지 않는다.

**Q13. 사람별 Macro F1의 평균이 전체 Macro F1과 다른 이유는?**

Macro F1은 비선형 지표다. 전체 1,775구간의 혼동행렬과 한 사람 안의 혼동행렬에서 계산한 F1은 단순 가중 평균 관계가 아니다. 그림 (b)를 전체 점수의 가산 분해로 설명하지 않는다.

**Q14. 수업 발표와 학회 논문이 같은 프로젝트면 중복인가?**

동일 프로젝트를 수업에서 설명하고 학회에 투고한다는 사실만으로 두 개의 학술지 논문이 자동 생성되는 것은 아니다. 다만 과거 공개·심사·게재 이력이 있으면 해당 학회의 현행 규정과 교수님 판단을 확인해야 한다. 수업용 발표와 이번 학회 원고의 성격을 구분하고 다른 연구의 문장·그림은 복사하지 않았다. 이 답변을 모든 학회에 대한 중복 게재 허용 선언으로 사용하지 않는다.

**Q15. 더 강한 논문으로 만들려면 무엇을 추가해야 하는가?**

복수 사람 분할의 재현성, 동일 용량 또는 탐색 예산을 고려한 비교, 규약을 고정한 독립 평가가 우선이다. 모바일 효율을 주장하려면 실제 기기 측정이 필요하다. 이 작업에서는 그 실험을 수행한 것으로 작성하지 않았다.

| 근거와 맞는 표현 | 피할 표현 |
| --- | --- |
| 이 고정 구성·개발 분할에서 관찰했다 | LSTM이 CNN과 동등한 최적 모델이다 |
| 세 seed의 표본 SD다 | 사용자 모집단의 신뢰구간이다 |
| 파라미터가 75.2% 적다 | 스마트폰에서 75.2% 더 빠르다 |

| 피험자 14가 네 구성에서 낮았다 | 특정 신체 특징이 원인임을 입증했다 |

사사는 사업 적용과 학교 문구가 확인된 뒤 확정한다. 저자 순서는 이봉헌·유재윤·정회서·한윤섭·최승빈, 지도교수는 황세웅으로 유지한다. 발표 내용은 저장 예측과 결과 CSV로 방어하고, 모르는 원인은 추정으로 표시한다.

## 검증 구성에 관한 추가 질문

**Q16. 낮은 피험자를 뺀 점수를 성능으로 보고하는 것 아닌가?**

대표 비교표는 전체 5명·1,775구간의 점수를 유지한다. 제외 진단은 다섯 사람을 각각 뺀 모든 경우를 함께 보고한다. 유리한 집단으로 모델을 선택·학습·대표 교체하지 않았고 제외 점수로 성능 향상을 주장하지 않는다.

**Q17. LOSO 교차검증인가?**

아니다. 동일한 저장 모델·예측에서 검증 집단만 다르게 집계했다. LOSO의 사람 분할마다 재학습과 평가를 반복하는 실험은 수행하지 않았다. 새로운 다중 분할 검증을 대신하지 않는다.

**Q18. 피험자 14가 순위를 바꾸는 원인임을 입증했는가?**

아니다. 제외 시 표본 수와 클래스 구성도 달라진다. 고정 예측에서 집단 구성이 달라지면 평균 순위도 달라질 수 있다는 사후 관찰이다. 사람의 특정 특성이나 독립적 인과 효과를 측정하지 않았다.

**Q19. 추가 지표는 어떻게 검증했는가?**

12회 예측의 ID·사람·정답 대응과 여섯 라벨을 검사했다. 전체+5제외의 72개 경우를 혼동행렬에서 재계산하고 scikit-learn의 six-class Macro F1·Accuracy와 대조했다. 원래 전체 지표도 이전 감사와 일치한다. CSV·계산 코드·원본 해시를 공개한다.
