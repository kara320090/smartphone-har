# v6 지면과 연구 그림 편집 기록

2026-10-14 · **스마트폰 행동 인식 신경망의 성능·규모 절충과 피험자별 편차 분석**

공식 대학생 양식의 용지·여백·제목·저자 표기·본문 휴먼명조 10pt·160% 줄 간격을 유지했다. 첫 페이지와 결과 설명은 2단으로, 둘째 페이지의 통합 결과 그림만 양단 폭으로 배치했다. 한글 저장·재로딩과 PDF 내보내기 결과는 모두 두 쪽이다.

| 개체 | 설계 | 설명할 내용 |

그림 2는 170×54mm의 단일 세 패널 그림으로 묶었다. 각 패널의 의미와 단위를 별도로 표시하고 숫자를 적어 색에만 의존하지 않도록 했다. LSTM의 강조색은 산점도와 구조도에서 유지했다. 600dpi PNG와 SVG를 제공한다.

## 해석과 반올림

CNN 평균 Macro F1 0.8889, LSTM 0.8813, 차이 0.0076을 유지한다. LSTM의 파라미터 수는 CNN보다 75.2% 적다. 이는 파라미터 수의 비교이며 실제 스마트폰 지연·전력 측정이나 통계적 동등성이 아니다.

열지도와 막대의 라벨은 소수 세 자리다. 전체 +0.008은 원래 +0.0075933765, 피험자 14 제외 −0.004는 원래 −0.0044281056을 반올림했다. 표·본문은 네 자리이며 `VISUAL_FIGURE_DATA.json`에는 반올림 전 값과 그림 해시가 있다.

피험자 제외 진단에서는 표본 수와 클래스 구성도 변한다. 인과 효과·성능 개선·LOSO 재학습 교차검증으로 표현하지 않는다. 검증은 epoch 선택에 사용한 개발 자료이며 공식 test는 미평가다. 학습 환경·모델 용량·헤드·Dropout·탐색 예산의 차이는 한계로 남겼다.

## 출처와 재생성

- 성능·규모: `reports/team_comparison/baseline_summary.csv`.
- 피험자별 값: `reports/team_error_analysis/subject_summary.csv`.
- 구성 진단: `reports/subject_composition/paired_seed_gaps.csv`.
- 그림 코드: `tools/make_research_figure.py`.
- 진단의 72개 지표 대조 근거: `diagnostic_data/analysis.json`.

```powershell
python tools/make_research_figure.py --output docs/dcs-team-paper-research-v6
```

이 명령은 그림과 표시 데이터 JSON을 재생성한다. HWP의 그림 자동 갱신 또는 학습을 수행하지 않는다. 최종 한글 원고는 첨부 양식을 바탕으로 제작한 native HWP이며 기존 결과와 본문·표·그림을 대조했다. 모든 PDF 페이지를 150dpi로 렌더링해 글자·축·표·캡션의 잘림과 겹침을 확인했다.

참고문헌은 데이터 UCI HAR와 사용자 의존·독립 평가를 다룬 Scheurer 등의 연구 두 개다. 본문에서 압축한 선행 연구와 하계 논문 5편·11쪽의 검토는 별도 기록에 보존했다. 수상 여부나 공식 심사 배점을 확인한 것으로 표현하지 않는다. 새로운 학습·대표 모델 교체·점수 변경은 없다.

공개 원고의 사사는 확인 후 기재 예정이며 학교 별첨은 사사 확인용 초안이다. 최종 투고·메일 발송은 완료하지 않았다.
