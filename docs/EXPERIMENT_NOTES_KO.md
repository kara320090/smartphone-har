# 학습 조건 실험의 가설과 해석

모든 관측은 실제 저장된 검증 결과에서 계산했다. 같은 seed 2026의 1회 실행이므로 반복 실험의 평균·표준편차나 통계적 유의성을 주장하지 않는다. 실험 ID는 config 파일과 결과 폴더를 연결한다.

## E02 기준 특징 MLP

가설은 공식 561 특징이 행동 구분에 필요한 정보를 요약하므로 작은 MLP로 분류 기준을 만들 수 있다는 것이다. 학습 16명·검증 5명, 표준화, Adam 0.001, batch 64, 최대 40 epoch를 사용했다.

Accuracy 0.9161, macro F1 0.9138. 최저 검증 손실은 epoch 2였고 epoch 8에 조기 종료했다. 이후 학습 손실은 계속 줄지만 검증 손실이 높아지는 곡선은 과적합 가능성을 보여준다. 사람별 동작 차이 또는 표본 구성의 영향도 있으므로 학습 곡선 하나로 원인을 확정하지 않는다.

## E03 시계열 MLP

128×9 신호를 모델 내부에서 펼쳐 같은 은닉층에 입력한다. 시계열 자체의 정보를 학습할 수 있는지 확인하되, Flatten은 시간 구조를 합성곱이나 순환층처럼 명시적으로 반영하지 않는다.

macro F1 0.8765로 E02 대비 3.73 percentage points 낮았다. 입력 표현이 달라지고 파라미터도 156,230개로 늘었으므로 차이를 Flatten 또는 모델 크기 한 가지로 설명할 수 없다. 특징 설계, 모델 용량, 최적화 차이가 함께 작용할 수 있다.

## E07 표준화 제거

입력 스케일을 맞추면 학습에 도움이 될 것이라는 가설을 비교한다. 입력·분할·모델·학습률은 E02와 같고 표준화만 제거했다.

macro F1 0.8864로 2.74 percentage points 낮았다. 이번 분할에서는 표준화된 기준이 더 높았지만 원 특징이 이미 대체로 -1~1 범위로 가공되었다는 조건을 함께 설명해야 한다. 최소 검증 교차엔트로피는 E07이 더 낮아도 macro F1는 더 낮을 수 있다. 손실은 예측 확률을, F1는 최종 클래스 결정을 평가하기 때문이다.

## E08 Dropout 0.3

은닉층 둘 뒤의 Dropout이 과적합을 줄일 수 있다는 가설이다. 모델의 학습 가능한 파라미터 수는 E02와 같다. Dropout은 학습 중에만 적용하고 평가·시연에서는 끈다.

macro F1 0.8940으로 기준보다 1.99 percentage points 낮았다. 이번 조건에서는 개선을 관측하지 못했다. Dropout 비율, 정해진 학습 길이, 난수 마스크와 사람 분포가 영향을 줄 수 있다. 한 비율과 한 seed의 결과로 Dropout이 언제나 불필요하다고 결론 내리지 않는다.

## E09와 E10 학습률 변경

작은 학습률은 더 작은 갱신으로 수렴하고 큰 학습률은 빠르게 이동하지만 불안정할 수 있다는 가설이다. E09는 0.0003, E10은 0.003이며 나머지는 E02와 같다.

E09 macro F1는 0.8749로 기준 대비 3.90 percentage points 낮았다. E10은 0.8899로 2.40 percentage points 낮았다. E10의 최저 검증 손실은 epoch 1이며 이후 곡선 변동이 컸다. 두 조건 모두 지정된 조기 종료 규칙 안에서는 개선을 보이지 않았다. 학습률과 최선 epoch가 상호작용하므로 결과는 이 학습 예산과 종료 기준에 한정한다.

## E11 PCA 95%

분산 95%를 남기는 압축으로 입력 차원을 줄였을 때 분류 정보가 얼마나 남는지 확인한다. PCA는 학습 부분에서만 계산했다. 561차원이 실제로 100차원으로 줄었고 MLP 파라미터는 80,582개에서 21,574개로 줄었다.

macro F1는 0.8795로 기준보다 3.43 percentage points 낮았다. 표현을 줄인 결과 모델도 작아졌으므로 분류 차이는 정보 제거와 모델 용량 변화 모두에 영향을 받는다. 큰 분산을 보존하는 목적은 정답을 잘 구분하는 목적과 같지 않다. 이 실험은 ①의 PCA·군집 분석을 대신하지 않으며, 팀 전처리 모듈로 바꿀 때 수치 일치를 확인해야 한다.

## 공통 학습 개념

`tf.data`의 shuffle은 학습에만 사용한다. cache는 반복 읽기를 줄이고 batch는 기울기 갱신 단위를, prefetch는 다음 배치 준비를 담당한다. TFRecord는 학습 자료 200개를 저장·복원하여 입력 값과 순서, shape, 정답, 사람, sample_id가 정확히 같은지 확인했다. 전체 학습은 데이터가 작으므로 배열 기반 파이프라인을 유지한다.

TF Transform은 학습 때 계산한 변환을 추론에서 동일하게 사용하는 개념과 연결한다. 이 프로젝트는 저장한 mean·scale·PCA 축을 재사용하는 방식으로 그 일관성을 검증하며 TFX/TF Transform 서비스를 구축한 것으로 주장하지 않는다.

## 선택 범위

이 7개 중에는 E02가 검증 macro F1가 가장 높다. 팀 전체 E01–E13과 seed 반복을 확인하기 전 최종 시연 모델로 확정하지 않는다. 시험 점수는 아직 없으며, 데이터 수집 위치·기종이 달라질 때의 성능도 검증하지 않았다.
