비교 논문에도 제한은 있다. 스쿼트 논문의 80/20 분할은 본문에서 사람 독립성을 명확히 밝히지 않았다. HMD 논문의 본문 인용과 참고문헌 목록, 이상거래 논문의 본문·표 일부 수치에는 확인이 필요한 부분이 있었다. 따라서 보고 방식을 참고하되, 해당 논문의 모든 주장과 설계가 검증되었다고 간주하지 않았다. 문장·그림·결과를 복사하지 않았다.

## v8가 약했던 이유

1. 6종을 3상태로 묶어 높은 점수가 나온 것만으로는 연구 질문에 충분히 답하지 못했다. 과제가 쉬워졌다는 설명을 넘는 대조가 없었다.
2. 단순 모델과 비교하지 않아, 요약을 위해 신경망이 필요한지 판단할 수 없었다.
3. 앱 활용 이야기가 실제 측정 결과와 떨어져 있었다. 지속시간·휴대 위치·실기기 동작을 확인하지 않은 상태였다.
4. 결론이 “모델별 점수를 비교했다”에서 끝나, 독자가 다음 설계 결정을 내릴 근거가 약했다.

## 이번에 추가한 근거

### 대조 1: 고정한 선형 기준선 두 번 학습

같은 학습 5,577구간과 개발 검증 1,775구간에서 채널 평균·표준편차 18개를 입력했다. 특징 표준화는 학습 자료에만 적합했다. 6종 로지스틱 회귀 LR6와 직접 3상태를 학습한 LR3의 조건은 실행 전에 고정했다.

| 조건 | 분류기 가중치·편향 수 | 6종 Macro F1 | 3상태 Macro F1 | 검증 오류 |
| --- | ---: | ---: | ---: | --- |
| LR6 | 114 | 0.7742 | 0.9985, 6종 예측 매핑 | 6종 372개 / 3상태 2개 |
| LR3 | 57 | 해당 없음 | 1.0000, 직접 학습 | 3상태 0개 / 1,775개 |

LR은 각 한 번 학습했다. 반복 seed 실험인 것처럼 SD 0을 붙이지 않았다. 새 프로세스에서 저장한 계수·표준화값으로 전 구간을 다시 예측해 클래스와 확률이 일치하는지 확인했다. 이 결과는 **신경망이 항상 필요하다는 주장에 반하는 대조**다. 단일 개발 분할에서 무오류였다고 실생활 100% 성능을 의미하지 않는다.

### 대조 2: 동일 그룹 크기의 모든 60개 매핑

6개 행동을 3·2·1개씩 묶는 방법은 6×C(5,2)=60개다. 기존 12회 신경망 예측 각각에 모두 적용해 **720건의 지표를 재계산**했다. 모델별 세 seed 평균에서 원래 의미 기반 매핑은 모두 유일한 1위였다. 전체 매핑의 F1 중앙값은 MLP 0.8806, CNN 0.8995, RNN 0.7775, LSTM 0.8950이었다.

이는 “어떤 행동을 합쳐도 같은 높은 점수가 되는가”를 살피는 기술적 대조다. 매핑마다 클래스별 표본 수가 달라 독립 검정이나 유의확률로 해석하지 않는다. 가장 높은 매핑을 찾아 원래 정의를 바꾼 것도 아니다. 의미 기반 매핑은 이전 v8에 이미 정해져 있었다.

## 새 결론과 실제 활용의 연결

**활동 기록에서 필요한 구분 수준을 먼저 정한 뒤, 그 수준의 오류와 분류기 복잡도를 비교한다.** 이번 구성에서는 세부 행동에 CNN·LSTM의 이점이 있었지만 큰 상태 요약에는 단순 통계·선형 모델도 가능했다. 따라서 이동·자세 상태를 표시하는 기초 모듈은 단순 모델부터 검토할 수 있고, 계단·앉기를 기록하려면 세부 지표로 다시 선택해야 한다.

이것은 앱 배포 결과나 새로운 LSTM 알고리즘의 제안이 아니다. 더 나은 특징을 설계한 다른 선형 모델의 성능도 배제하지 않는다. 본문 그림 1은 실제 비교 경로, 그림 2는 60개 매핑의 민감도, 표 1은 네 신경망과 두 선형 조건의 수치를 각각 담당한다.

## 여전히 남은 한계

- 단일 사람 분할의 개발 검증이다. 신경망은 이 validation으로 epoch를 선택했다. 공식 test는 사용하지 않았다.
- 네 신경망은 입력 구간은 같지만 용량·헤드·Dropout이 달라 순수 구조 효과만 분리한 실험이 아니다.
- 선형 기준은 통계 특징을 사용하므로 입력 표현과 분류기가 함께 달라진다. 신경망 구조만의 인과적 효과로 해석하지 않는다.
- 57개는 분류기 계수·편향 수다. 표준화 상수와 특징 계산 비용까지 포함한 전체 배포 비용이 아니며 지연·전력을 측정하지 않았다.
- 허리 착용 데이터의 제한된 동작이다. 주머니·손에 든 위치, 전환 동작, 연속 앱 기록은 후속 검증이 필요하다.
- 수상·채택 가능성을 실험이나 편집으로 보장할 수는 없다. 지도교수·공동저자 검토가 남아 있다. 사사 문구는 2026-10-19 사용자 요청으로 컴퓨터비전 논문과 동일하게 반영했다.
