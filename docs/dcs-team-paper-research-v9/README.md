# DCS 대학생 논문 v9

2026-10-19 · **스마트폰 활동 요약을 위한 행동 구분 수준과 분류기 복잡도 분석**

[수정 가능한 공식 한글 원고](DCS_2026_대학생_논문개정_v9.hwp) · [두 쪽 PDF](DCS_2026_대학생_논문개정_v9.pdf) · [동일 본문 Markdown](DCS_TEAM_PAPER_KO.md)

v8의 비교 근거 부족을 보완하기 위해 선형 기준선 두 조건을 실제 학습하고 동일 그룹 크기의 60개 매핑을 대조했다. 제목·연구 질문·그림·표·결론을 이 결과를 중심으로 다시 작성했다. 다른 대학 네 편의 두 쪽 논문 전체를 다시 확인한 근거는 [비교 검토](PROCEEDINGS_COMPARISON_KO.md)에 남겼다.

- 그림 1: 실제 수행한 시계열·통계 특징 비교 경로
- 표 1: MLP·CNN·RNN·LSTM·LR6·LR3의 분류기 규모와 출력 수준별 F1
- 그림 2: 60개 행동 매핑의 분포와 의미 기반 매핑
- 참고문헌 2개. 본문 휴먼명조 10pt·원양식 160% 줄 간격·2단·여백을 유지했다.

결론은 출력 목적에 맞는 복잡도 선택이다. 큰 상태 요약에서는 단순 선형 모델도 가능했으므로 신경망의 우월성을 주장하지 않는다. CNN·LSTM은 비교한 입력·분류기 구성의 세부 구분에서 LR6보다 높았다.
