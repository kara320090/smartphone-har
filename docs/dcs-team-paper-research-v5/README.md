저자 순서는 **이봉헌·유재윤·정회서·한윤섭·최승빈**, 제1저자·발표자는 이봉헌, 지도교수는 황세웅이다. 소속·학생 이메일은 제공된 응용프로젝트 프로필에서 확인한 정보를 유지했다. 교수님을 공동저자·교신저자로 자동 추가하지 않았다.

사사 적용·최종 문구와 교신저자·최종 투고 내용은 확인할 항목이다. 공개 원고에 지원 사실을 확정하는 사사는 넣지 않았다. 학교 지원 서류·학번·전화번호·동의서와 타인 논문 전문은 공개하지 않는다. 학교 별첨용 사사 확인 파일은 로컬에 따로 보관한다.

## 결과의 범위

- 대표 결과는 전체 개발 검증 5명·1,775구간, M01·C01·R01·L01의 세 seed다. 검증은 epoch 선택에도 사용했다.
- 그림 2는 파라미터 수의 로그 축과 seed 표본 SD다. 신뢰구간·모바일 속도·전력 측정이 아니다.
- 그림 3(a)는 각 사람의 6클래스 Macro F1 seed 평균이며 전체 점수의 단순 가산 분해가 아니다.
- 그림 3(b)는 저장 예측에서 집단을 바꿔 집계한 사후 진단이다. 표본 수·클래스 구성도 변하고 재학습하지 않았다. 대표 결과는 전체 5명을 유지한다.
- 새 학습·모델 선택 변경·LOSO 재학습 교차검증·공식 test 평가는 없다. 통계적 동등성·유의성·최적 구조를 주장하지 않는다.

새 그림은 `tools/make_paper_visuals.py`로 재생성한다. 구성 진단은 `tools/analyze_subject_composition.py`에서 계산했다. [앞선 v4](../dcs-team-paper-research-v4/README.md)와 기존 상세 보고서·수업 PPT는 수행 기록으로 보존한다. 이 자료는 제출·채택·수상을 완료한 원고가 아니다.
