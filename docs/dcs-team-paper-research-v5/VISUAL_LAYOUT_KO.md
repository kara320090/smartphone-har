# 그림을 늘리고 참고문헌을 줄인 v5 편집

2026-10-14 · 공식 대학생 한글 양식의 **두 쪽·본문 10pt·2단·여백**을 유지했다. 제목·저자 순서·소속·이메일·지도교수, 대표 구성과 결과 지표는 변경하지 않았다.

## 본문에서 읽는 순서

| 본문 개체 | 보여 주는 내용 | 읽을 때의 기준 |
| --- | --- | --- |
| 그림 1. 공통 개발 실험과 분석 흐름 | 제공 시계열→사람 분할→학습 통계 표준화→네 구성×세 seed→검증 손실로 epoch 선택→성능·규모와 피험자 진단 | 검증은 모델 epoch 선택에도 사용한 개발 자료다. 독립 test가 흐름에 들어가 있지 않다. |
| 표 1. 개발 검증 성능과 모델 규모 | 네 기준 구성의 파라미터 수, Accuracy·Macro F1 평균 및 seed 표본 SD | 원래 지표의 정확한 소수값과 기준 구성 M01·C01·R01·L01을 유지한다. |
| 그림 2. 파라미터 수와 개발 검증 성능 | 네 모델의 성능·규모 절충을 산점도와 오차막대로 제시 | 가로축은 파라미터 수의 로그 축이다. 세 seed의 표본 SD이며 사용자 신뢰구간이 아니다. 파라미터 수로 스마트폰 속도를 주장하지 않는다. |
| 그림 3(a). 피험자별 성능 | 다섯 사람 안에서 계산한 6클래스 Macro F1의 seed 평균과 표본 수 | 피험자 14의 낮은 성능을 평균 전체 점수와 함께 해석한다. 사람별 F1은 전체 점수의 가산 분해가 아니다. |
| 그림 3(b). 검증 구성 민감도 | 전체 및 각 사람 제외 진단에서 CNN-LSTM 평균 차이 | 양수는 CNN 평균이 높고 음수는 LSTM 평균이 높다는 뜻이다. 다섯 제외 경우를 모두 표시하며 대표 결과는 전체 5명이다. |

그림 3의 막대 라벨은 좁은 지면의 가독성을 위해 소수 세 자리로 표시했다. 예를 들어 전체 +0.008은 원래 차이 +0.0075933765를 반올림한 값이다. 본문은 네 자리 0.0076을 사용하며 `VISUAL_FIGURE_DATA.json`에는 반올림 전 값이 있다.

## 참고문헌을 줄인 방식

본문 참고문헌을 기존 **4개에서 2개**로 줄였다. 실제 데이터 출처인 UCI HAR와 사용자 의존·독립 평가를 다룬 Scheurer 등의 연구를 남겼다. 본문의 인용 번호도 [1]·[2]로 다시 연결했다. CNN·LSTM 적용 자체를 새로운 연구라고 주장하는 문장은 넣지 않았다.

Anguita 등의 원논문, Ordóñez와 Roggen의 DeepConvLSTM, Hammerla 등의 비교 연구 및 타 대학 사례 검토는 `PROCEEDINGS_REVIEW_KO.md`, `SOURCE_INDEX.json`과 이전 v4 연구 보강 기록에 남긴다. 본문 공간을 줄인 것이 선행 연구를 확인하지 않았다는 뜻은 아니다. 상세 검토 전문·타인 그림을 공개 묶음에 복사하지 않았다.

## 그림의 데이터와 제작

- 입력과 분할: 제공된 128×9 시계열, 학습 16명·5,577구간과 개발 검증 5명·1,775구간.
- 성능·규모: `reports/team_comparison/baseline_summary.csv`.
- 피험자별 성능: `reports/team_error_analysis/subject_summary.csv`.
- 구성 진단: `reports/subject_composition/paired_seed_gaps.csv`.
- 제작 코드: `tools/make_paper_visuals.py`. Matplotlib로 만든 600dpi PNG와 SVG를 제공한다.
- 정확한 표시 데이터·의미·그림 해시: `VISUAL_FIGURE_DATA.json`.

```powershell
python tools/make_paper_visuals.py --output docs/dcs-team-paper-research-v5
```

기존 보충 그림 `class_subject_f1.*`, `subject_composition.*`와 진단 CSV를 보존했다. 새 학습·모델 대표 교체·공식 test 평가는 없다. HWP 안의 세 PNG를 원본 바이트와 대조하고, 본문·표·차트 데이터가 원자료 CSV와 일치하는지 검사했다. HWP를 저장·다시 불러온 뒤 모든 PDF 페이지를 렌더링해 한글·숫자·축·범례·표의 잘림과 겹침을 확인한다.

공개 원고의 사사는 확인 후 기재 예정이고 학교 별첨은 사사 확인용 초안이다. 최종 제출 확정 및 기관에 대한 접수·메일 발송은 하지 않았다.
