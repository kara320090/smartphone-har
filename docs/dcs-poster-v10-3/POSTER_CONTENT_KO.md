01  연구 질문과 기여

활동 요약에 필요한 구분 수준이
모델 선택을 어떻게 바꾸는가?

같은 3상태에서 예측 병합과 직접 학습을 대조했다.
동일 18개 특징의 로지스틱 회귀(LR)·MLP와
시계열 모델을 사람 독립 test·처리 비용으로 비교했다.

| 원래 6종 행동 | 활동 요약 3상태 |
| --- | --- |
| 걷기 · 계단 오르기 · 내리기 | 이동 |
| 앉기 · 서기 | 앉거나 서 있음 |
| 눕기 | 누워 있음 |

02  데이터와 평가

UCI HAR [1] · 허리 착용 · 가속도·각속도
9채널 × 128시점 · 50Hz · 2.56초 · 50% 중첩

| 구분 | 사람 | 센서 구간 |
| --- | --- | --- |
| 학습 | 16명 | 5,577 |
| 검증 | 5명 | 1,775 |
| 공식 test | 9명 | 2,947 |

사람을 분리하고 학습 통계로 표준화했다.
모델·조건 고정 후 공식 test를 평가했다.

NN: seed 2026·2027·2028, Adam 0.001, batch 64,
최대 40 epoch, 검증 손실 patience 6·최선 가중치 복원

03  핵심 결과: 분류 목표와 처리 비용

공식 test Macro F1

| 모델 | 6종 | 6종→3 | 직접 3 |
| --- | --- | --- | --- |
| MLP | 0.8816 ±0.0164 | 0.9796 ±0.0031 | 0.9918 ±0.0024 |
| CNN | 0.9053 ±0.0136 | 0.9950 ±0.0027 | 0.9962 ±0.0028 |
| RNN | 0.7217 ±0.0669 | 0.9788 ±0.0076 | 0.9905 ±0.0027 |
| LSTM | 0.8767 ±0.0183 | 0.9866 ±0.0065 | 0.9959 ±0.0029 |
| LR | 0.7486 | 0.9865 | 0.9994 |
| FMLP | - | - | 0.9986 ±0.0002 |

NN은 3 seed 평균±표본 SD, LR은 단일 학습.
6종→3: 6종 argmax 예측을 3상태로 병합.
FMLP: 18개 통계 특징을 입력으로 사용한 MLP.
6종과 3상태는 서로 다른 분류 과제이다.

직접 3상태 F1  0.9905–0.9994

네 NN의 평균 F1은 병합보다 높았다.
동일 seed 12쌍 중 11쌍 증가; LSTM 2027은 −0.0011.

05  활용에 따른 구성 선택

활동 상태 표시·구간별 태그

카메라·GPS 없이 3상태 태그를 생성하는 구성은
높은 F1을 보인 모델의 비용을 함께 검토한다.

좌식·계단 이용 기록
