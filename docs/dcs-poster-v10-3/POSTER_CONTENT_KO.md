01  연구 기여와 비교 설계

출력 목표·입력 표현·처리 비용을
사람 독립 평가에서 함께 대조

목표: 6종 예측 병합 vs. 3상태 직접 학습
입력: 18개 특징의 로지스틱 회귀(LR3) vs. FMLP3
비용: 같은 CPU의 전처리·분류·반환 시간

| 원래 6종 행동 | 활동 요약 3상태 |
| --- | --- |
| 걷기 · 계단 오르기 · 내리기 | 이동 |
| 앉기 · 서기 | 앉거나 서 있음 |
| 눕기 | 누워 있음 |

특징·계층 분류 선행연구 [2,3]를 토대로,
출력 요구별 구성 선택의 실험 근거를 제시한다.

128시점 · 50Hz · 2.56초 · 50% 중첩

사람을 분리하고 학습 통계로 표준화했다.

신경망: seed 2026·2027·2028, Adam 0.001, batch 64,
최대 40 epoch, 검증 손실 patience 6·최선 가중치 복원
입력: 시계열 4종 128×9 / LR·FMLP 18개 특징

03  핵심 결과: 분류 목표와 처리 비용

공식 test Macro F1 (클래스별 F1 평균)

| 모델 | 6종 | 6종→3 | 직접 3 |
| --- | --- | --- | --- |
| MLP | 0.8816 ±0.0164 | 0.9796 ±0.0031 | 0.9918 ±0.0024 |
| CNN | 0.9053 ±0.0136 | 0.9950 ±0.0027 | 0.9962 ±0.0028 |
| RNN | 0.7217 ±0.0669 | 0.9788 ±0.0076 | 0.9905 ±0.0027 |
| LSTM | 0.8767 ±0.0183 | 0.9866 ±0.0065 | 0.9959 ±0.0029 |
| LR | 0.7486 | 0.9865 | 0.9994 |
| FMLP | - | - | 0.9986 ±0.0002 |

신경망: 3 seed 평균±표본 SD / LR: 단일 학습.
SD는 학습 변동이며 사람 모집단의 신뢰구간과 구분한다.
6종→3: 6종 argmax 후 병합. 6종·3상태는 별도 과제.
FMLP는 18특징 MLP로, 시계열 MLP와 입력이 다르다.

직접 3상태 F1  0.9905–0.9994

위 범위는 신경망 평균과 LR 단일 적합의 범위이다.
직접 학습은 같은 seed 12쌍 중 11쌍에서 F1 증가.
LSTM 2027은 −0.0011로 예외도 관찰됐다.

05  활용에 따른 구성 선택

활동 일지의 구간별 상태 표시

카메라·GPS 없이 이동·앉거나 서 있음·누워 있음 태그.
요약 목표에는 높은 F1을 보인 구성의 비용을 비교한다.

좌식·계단 이용의 세부 기록

앉기·서기, 걷기·오르기·내리기 라벨을 보존한다.
6종 F1: CNN 0.9053, LR6 0.7486.
