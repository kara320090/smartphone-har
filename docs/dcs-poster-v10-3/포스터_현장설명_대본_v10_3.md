# 실제 포스터 설명 순서 · v10.3

스마트폰 센서 기반 활동 요약을 위한 분류 목표와 모델 구성 비교

발표자 이봉헌 · 선문대학교 AI소프트웨어학과 · 지도교수 황세웅

## 30초 핵심 설명

스마트폰 센서로 활동을 요약할 때 필요한 행동 정보를 먼저 정하고 모델을 고르는 연구입니다. 사람을 분리한 공식 test에서 직접 3상태 분류의 대표 F1은 0.9905~0.9994로 높게 모였지만, 같은 특징을 쓰는 LR3와 FMLP3의 PC 처리 시간은 약 14.2배 차이가 났습니다. 반면 6종 행동에서는 CNN과 LR의 결과가 달라졌습니다. 이 결과로 활동 요약과 세부 행동 기록에 맞는 구성을 선택할 근거를 제시합니다.

## 포스터 앞 3분 설명

### 1. 제목 아래 결론과 왼쪽 위: 연구 질문 (약 30초)

안녕하세요. 발표자 이봉헌입니다. 이 연구는 어떤 모델이 무조건 좋은지보다 활동 기록에 어떤 정보가 필요한지를 먼저 묻습니다. 이동 중인지, 앉거나 서 있는지, 누워 있는지를 요약하는 목적과 좌식 시간·계단 이용을 구분하는 목적은 필요한 출력이 다릅니다. 그래서 같은 세 상태를 얻는 예측 병합과 직접 학습을 비교하고, 같은 통계 특징의 선형 모델과 MLP도 대조했습니다.

### 2. 오른쪽 위: 평가 조건 (약 30초)

UCI HAR의 허리 착용 스마트폰 데이터를 사용했습니다. 한 구간은 2.56초이며 가속도와 각속도의 아홉 채널을 사용합니다. 사람 기준으로 학습 16명, 검증 5명, 공식 테스트 9명을 분리했고, 조건과 모델을 고정한 뒤 2,947개 테스트 구간을 평가했습니다. 신경망은 세 seed를 모두 보고했고 LR은 한 번 학습한 결과입니다.

### 3. 가운데 표와 그래프: 주요 결과 (약 60초)

표의 세 열은 여섯 행동 분류, 여섯 행동 예측을 세 상태로 병합한 결과, 처음부터 세 상태를 학습한 결과입니다. 여섯 행동과 세 상태는 다른 과제이므로 두 점수 차이를 모델 개선으로 읽지 않습니다. 같은 세 상태끼리 비교하면 네 신경망의 직접 학습 평균 F1이 높았고, 같은 seed 열두 쌍 중 열한 쌍에서 증가했습니다. LSTM의 한 seed는 감소했습니다.

직접 세 상태의 대표 점수는 모두 높은 범위에 모여 있습니다. 따라서 LR3의 작은 점수 우위를 모델 자체의 우월성으로 주장하지 않습니다. 대신 같은 열여덟 특징의 LR3와 FMLP3에서 파라미터는 57개와 10,883개, PC 구간 처리 시간은 0.073밀리초와 1.043밀리초로 달랐다는 점에 주목합니다. 약 14.2배의 관측 비용 차이이며, 그래프는 스마트폰 실기기 속도가 아닙니다.

### 4. 왼쪽 아래: 실제 센서 입력 사례 (약 25초)

왼쪽 아래는 실제 테스트 구간의 신체 가속도 세 축입니다. 원래 걷기인 이 구간에서 LR3가 이동 태그를 반환했습니다. 그림은 세 축만 보여주지만 분류에는 아홉 채널의 평균과 표준편차, 총 열여덟 특징을 사용합니다. 이런 출력은 카메라나 GPS 없이 구간별 활동 상태를 표시하는 구성에 연결할 수 있습니다.

### 5. 오른쪽 아래: 활용과 결론 (약 35초)

활동 상태 요약이라면 높은 분류 성능을 보인 구성의 처리 비용을 함께 검토할 수 있습니다. 반면 앉아 있는 시간이나 계단 이용을 구분하려면 앉기·서기와 걷기·오르기·내리기 라벨을 유지해야 합니다. 여섯 행동에서는 CNN F1이 0.9053, LR은 0.7486이었습니다. 결론은 보존할 행동 정보를 먼저 정하고, 그 목표 안에서 성능과 비용을 비교해 구성을 선택한다는 것입니다.

## 질의응답 연결

- **LR이 최고라는 뜻인가요?** 작은 F1 차이로 우월성이나 통계적 동등성을 주장하지 않습니다. 같은 18특징에서 관측된 비용 차이가 구성 선택 근거입니다.
- **과제를 단순화해서 점수가 오른 것 아닌가요?** 6종과 3상태는 별도 과제입니다. 직접 학습의 효과는 같은 3상태에서 예측 병합과 비교합니다.
- **스마트폰에서도 0.073ms인가요?** Intel Core i9-13980HX의 준비된 입력 처리 시간입니다. 전처리·특징·분류·반환을 포함하며 센서 수집·필터링·구간화·초기 로딩을 제외합니다.
- **하루의 좌식 시간이나 수면 시간을 측정한 것인가요?** 평가 단위는 허리 착용 6동작의 센서 구간입니다. 앉거나 서 있음은 좌식 시간을 분리하지 않고, 누워 있음은 자세 라벨입니다. 활용 예시는 출력 설계입니다.
- **다른 사람이 사용해도 되나요?** 학습과 공식 test 사람을 분리한 결과입니다. 평가 범위는 UCI HAR의 허리 착용 조건입니다.
- **재현 근거는 어디에 있나요?** 포스터 QR의 GitHub에 고정 모델·예측·지표와 논문 버전을 연결했습니다.
