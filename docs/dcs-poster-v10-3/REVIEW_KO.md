# 포스터 심사 관점 검토와 보완 · r1

2026-10-23 · 논문 기준 v10.3 · A0 세로형

## 종합 판단

원래 포스터에 논문과 어긋나는 F1·파라미터·처리 시간은 없었다. 약점은 수치보다 **기여의 제시 방식, 비용 수치의 해석 범위, 활용 설명의 구체성**이었다. 단순히 모델별 점수를 나열한 것으로 읽히지 않도록, 연구를 구성하는 세 대조와 출력 요구에 따른 선택 기준을 앞에 배치했다.

이 연구의 기여는 **출력 목표, 동일 특징의 분류기 대조, 고정 PC의 처리 비용을 사람 독립 평가에 연결한 실험적 선택 근거**이다. 새 신경망 구조나 새로운 활동 인식 알고리즘의 제안으로 설명하지 않는다. 통계 특징·계층 분류의 효용 자체는 선행연구에 있으므로, 그 효용을 최초로 발견했다는 주장은 피한다. [Wang 등, 2018](https://www.mdpi.com/1424-8220/18/11/3629), [Debache 등, 2020](https://pmc.ncbi.nlm.nih.gov/articles/PMC7308842/).

결론은 관측 결과에 부합한다. 활동 요약을 위한 3상태 직접 분류에서는 높은 F1을 보인 구성들이 서로 다른 비용을 보였다. 세부 행동이 필요한 경우에는 해당 라벨을 보존하고 그 목표의 지표로 구성들을 비교한다. 이 판단은 **고정된 UCI HAR 구성의 비교 결과**이며, 모델 계열 전체의 우열을 확정하는 주장과 구분한다.

## 심사 쟁점과 실제 반영

| 쟁점 | 기존 포스터에서의 위험 | 보완 내용 |
|---|---|---|
| 한눈에 보이는 결론 | ‘정보를 먼저 정하고 비용 비교’가 방법론적 구호처럼 보임 | 상단을 ‘3상태 요약은 성능·비용, 세부 기록은 필요한 라벨 보존’으로 구체화 |
| 연구 기여 | 서로 다른 비교가 한 문단에 묻힘 | 목표: 병합 대 직접 학습 / 입력: 동일 18특징 LR3 대 FMLP3 / 비용: 공통 CPU의 처리 범위를 각각 명시 |
| 선행연구와의 관계 | 단순 특징·행동 묶기 자체를 새 기여로 오해할 수 있음 | 기존 특징·계층 분류 연구 [2,3]와 연결하고 출력 요구별 구성 선택 근거로 기여를 한정 |
| 입력 통제 | LR·FMLP와 시계열 4종까지 같은 입력 표현으로 오해할 수 있음 | 시계열 4종은 128×9, LR·FMLP는 18개 특징이라고 구분 |
| 9채널 | 센서 9개 또는 가속도·각속도 6축과 혼동 | 신체 가속도·총 가속도·각속도의 각 3축임을 명시 |
| 지표 의미 | Macro F1을 정확도와 혼동 | 표 제목에 ‘클래스별 F1 평균’을 명시 |
| 높은 점수 범위 | 모든 개별 seed가 0.99 이상이라고 오해 | 0.9905~0.9994는 신경망 평균과 LR 단일 적합의 범위라고 바로 아래 설명 |
| 분류 목표의 차이 | 6종→3상태 점수 증가를 동일 과제의 성능 개선으로 해석 | 6종·3상태를 별도 과제로 명시하고, 직접 학습 효과는 같은 3상태끼리 설명 |
| 학습 변동 | 3 seed SD를 새로운 사람 모집단의 신뢰구간으로 해석 | SD의 의미를 표 바로 아래 설명 |
| 직접 학습의 예외 | ‘항상 더 좋다’는 일반화 | 12쌍 중 11쌍 증가와 LSTM 2027의 −0.0011을 유지 |
| 14.2배 | 방향이 불분명하거나 스마트폰 속도·에너지 개선으로 읽힘 | FMLP3/LR3의 PC 처리 시간 비율임을 명시하고, 점수·시간·파라미터를 함께 배치 |
| 비율과 반올림 | 표시된 1.043/0.073을 나누면 약 14.3이 나옴 | 14.2배가 반올림 전 원자료로 계산된 값임을 설명. 원자료 1.04275/0.0734 ≈ 14.2064 |
| 시간 표본 | 500회가 서로 다른 센서 구간 또는 test 전체라고 오해 | 그래프 바로 위에 검증의 동일 1구간·batch 1·CPU를 명시 |
| 실제 사례 | 잘 맞춘 한 사례만 보여 성공 사례 선택으로 보임 | 정분류 1구간이라고 명시하고, 전체 LR3 오류 2/2,947구간과 방향·사람을 함께 표시 |
| 오류의 독립성 | 겹치는 2구간을 독립된 2사건으로 표현 | 두 오류 구간이 중첩함을 명시. 실제 신호 64시점×9채널이 정확히 일치함을 대조 |
| 활용 | ‘활동 요약에 쓸 수 있다’로 끝남 | 활동 일지에 표시할 상태 태그를 명시하고 좌식·계단 기록에서 보존할 라벨을 나열 |
| 적용 범위 | 일상 생활 전체·수면·하루 지속시간 측정으로 확대 | 구간별 출력 설계, 허리 착용 6동작, 누워 있음은 자세라는 범위를 명시 |

## 수치 대조

논문의 표를 복사해 비교하는 데 그치지 않고 저장된 예측과 시간 측정 표본으로 다시 계산했다. 학습·모델 선택·새 test 예측은 실행하지 않았다.

| 지표 재계산 | 42개 실행·평가 수준 조합의 Macro F1·Accuracy·오류 수 일치 |
| 요약 | 16개 조건·수준 행의 평균·표본 SD 일치 |
| 포스터 F1 표 | 논문 v10.3 표 1의 6행·3평가 열과 표시값 일치 |
| 시간 | 각 실행의 500개 window_to_output 표본 중앙값과 조건별 중앙값 일치 |

## 발표에서 유지할 해석

**‘LR이 우월하다’보다 ‘이 요약 목표에서는 비용을 함께 볼 근거가 있다’가 결론이다.** 높은 F1의 작은 차이는 우월성이나 통계적 동등성을 증명하지 않는다. ‘직접 3상태에서 모든 실행이 0.99 이상’이라고 말하지 않고, 구성별 대표값의 범위라고 설명한다.

**같은 특징 대조와 모델 전체 비교를 분리한다.** LR3·FMLP3는 같은 18개 특징과 표준화·정답을 사용한다. 시계열 신경망과의 비교는 입력 표현·모델 크기·구현을 포함한 구성 비교이다. RNN·LSTM처럼 유닛 수와 파라미터가 다른 구성의 결과를 구조 하나의 인과 효과로 단정하지 않는다.

**0.073ms는 준비된 입력의 PC 처리 비용이다.** 2.56초 입력 창의 수집 시간, 최초 로딩, 스마트폰 에너지 소비와 별개다. 동일 입력 500회 측정은 반복 호출 비용을 보여주며, 다양한 활동 구간에 걸친 지연시간 분포를 뜻하지 않는다. NumPy와 TensorFlow 구현 차이도 비용에 포함된다.

**구간 태그와 하루의 활동 시간을 구분한다.** 50% 중첩 창의 길이를 모두 합하면 중복 시간을 세게 된다. 이 포스터는 구간별 태그의 구성 선택을 다룬다. 앉거나 서 있음으로 좌식 시간을 분리할 수 없고, 누워 있음을 수면으로 부르지 않는다. 허리 착용·정해진 6동작이라는 데이터 조건은 [UCI 공식 설명](https://archive.ics.uci.edu/dataset/240/human+activity+recognition+using+smartphones)에 근거한다.
