학회 안내에 따른 투고 파일은 **HWP**다. 현재는 교수님·공동저자 검토용으로, 투고·채택을 완료하지 않았다. 저자 순서는 이봉헌·유재윤·정회서·한윤섭·최승빈, 지도교수는 황세웅이다. 사사 적용 여부와 최종 문구는 확인 전이며 공개 원고에 지원 사실을 확정해 넣지 않았다. 학교 지원 확인용 사사 초안과 개인정보 포함 신청서는 로컬에서 별도로 보관한다.

## 이번 원고의 질문과 답

**질문:** 스마트폰 내장 센서로 활동 상태를 요약할 때에도 걷기·계단·앉기·서기 등의 모든 세부 동작을 구분해야 하는가?

**방법:** 기존 6종 argmax 예측과 정답을 같은 규칙으로 이동 / 앉거나 서 있음 / 누워 있음에 매핑했다. 확률 합산이나 새 계층형 신경망이 아니다. 과제·매핑은 결과를 본 뒤 탐색한 사후 분석으로 명시했다.

**관찰:** 네 기준 구성의 6종 오류 사건 중 98.1~99.9%는 같은 활동 상태 안의 세부 혼동이었다. 3상태 F1 평균은 0.9960~0.9998이지만, 6종과 다른 쉬운 과제이므로 성능 향상이라고 해석하지 않는다. 기준 RNN은 1,542개 파라미터로 큰 상태 요약을 위한 후속 검증 후보가 된다. RNN 우월성·통계적 동등성·실제 스마트폰 속도는 입증하지 않았다.

**활용:** 이동 여부나 큰 자세 상태를 구간별로 표시하는 기능의 모델 후보를 정할 수 있다. 계단 기록·앉은 시간처럼 세부 구분이 필요한 기능에는 같은 점수를 적용할 수 없다. 눕기는 수면이 아니다. 실제 앱·하루 타임라인·지속시간·임의 휴대 위치를 검증하지 않았다.

## 본문에 넣은 시각 자료

- 그림 1: 스마트폰 센서 → 6종 예측 → 고정 매핑 → 활동 상태 표시의 흐름. 검증 범위와 활용 제안을 구분했다.
- 표 1: 고정 M01·C01·R01·L01의 파라미터 수, 6종·3상태 Macro F1 평균과 seed 표본 SD. 네 모델 모두 동일한 개발 사람 분할의 세 seed다.
- 그림 2: 실제 6종 오류 중 상태 내 혼동과 상태 간 혼동의 수. 같은 1,775구간을 세 seed로 반복한 사건 수이며 독립 표본 5,325개가 아니다.
- L02는 보조 결과 한 문장으로만 넣었다. 기준 L01을 좋은 점수의 보조 구성으로 바꾸지 않았다.

## 근거와 재현

본문의 기준 12회, L02·L03을 포함한 전체 18회 분석은 [원자료](../../reports/output_granularity/README.md)에 있다. 기존 분석에서 31,950행의 ID·사람·정답 순서를 확인하고 전체 54개·사람별 270개 지표를 독립 구현과 대조했다. 이번 원고 작성에서는 그 CSV·감사 JSON과 본문·표·그림의 숫자를 대조했다. 학습이나 공식 test 평가를 새로 실행하지 않았다.

```powershell
python tools/make_paper_v8_figures.py
python tools/analyze_output_granularity.py --output reports/output_granularity_recheck
```

두 번째 명령에는 기존 저장 예측이 필요하며, LSTM 자료는 [LSTM Release](https://github.com/kara320090/smartphone-har/releases/tag/bongheon-lstm-v1)의 `runs/lstm`을 사용한다. 그림은 원자료로 생성한 PNG·SVG이며 다른 논문의 이미지를 복사하지 않았다.
