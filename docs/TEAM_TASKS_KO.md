# 팀장 진행 확인용 작업표

**현재 배정: 데이터 정회서 / MLP 한윤섭 / CNN 최승빈 / RNN 유재윤 / LSTM 이봉헌. 전처리 완료.** 현재 작업과 제출물은 [공동 논문 안내](team-paper/README.md)를 따른다.

아래 표는 역할 변경 전의 10주 프로젝트 연결 계획을 보존한 기록이다. 표의 ①~⑤는 예전 기능별 번호이며 현재 담당자에게 적용하지 않는다. 실제 메시지 발송·이슈 생성 기록을 뜻하지 않는다.

| 우선순위 | 담당 | 연결 작업 | 완료 조건 |
|---|---|---|---|
| 1 | 전원 | 입력·라벨·채널·sample_id 합의 | HANDOFF_KO의 정의와 동일하게 기록 |
| 1 | ① + ② | 데이터 모듈 연결 | 같은 표본의 특징·파형·분할·통계 일치 |
| 1 | ② + ⑤ | E02 저장물 인계 | 다른 환경에서 원 입력부터 동일 예측 |
| 2 | ③ + ② | 공통 모델 생성 연결 | 각 모델 입력 shape·6 logits 확인 |
| 2 | ② + ④ | 실험 설정과 지표 인계 | 같은 예측 CSV로 같은 macro F1 재계산 |
| 3 | ④ | 전체 기본 모델과 조건 비교 | E01–E13 및 지정된 반복 seed 결과 |
| 3 | 전원 | 8주차 설정 확정 | 선택 규칙·최종 평가 대상 고정 |
| 4 | ④ | 9주차 시험 평가 | 공식 시험 결과와 사람별 오류 보고 |
| 4 | ⑤ + 전원 | 시연·재현·발표 | 실행 가능한 저장물·오류 사례·질의응답 |

## 매주 확인할 네 가지

1. 이번 주 실제로 실행한 명령과 결과 파일은 무엇인가?
2. 다른 담당자에게 필요한 입력 또는 출력은 준비됐는가?
3. 오류의 입력, 메시지, 시도한 수정, 남은 문제가 기록됐는가?
4. 다음 주에는 어떤 확인 가능한 산출물을 남기는가?

## 변경 기록 양식

작업 날짜 / 담당 / 변경 파일 / 실행 ID / 바꾼 이유 / 결과 / 재현 명령 / 남은 의존성을 기록한다. 시행하지 않은 수정이나 사람이 확인하지 않은 항목을 완료로 표시하지 않는다.
