# 제출 전 확인 사항

파일은 첨부한 대학생 공식 양식의 실제 HWP이며 현재 2쪽이다. 형식 편집과 수치·배치 검증을 완료한 공동 초안으로, 학회에 제출한 상태가 아니다.

## 팀·지도교수와 확정할 내용

- [ ] 저자 명단과 순서, 한글 표기, 학교·학과·소속 기호, 각 저자 이메일.
- [ ] 교신저자와 이메일, †지도교수(Supervisor), 발표자.
- [ ] 정회서가 데이터 출처·신호 처리·채널·사람 분할·fit 통계 설명을 실제 수행 내용과 대조.
- [ ] 모든 담당자가 방법·그림·파라미터·결과를 원자료와 대조. 현재 MLP M01·CNN C01·RNN R01·LSTM L01 기준이다.
- [ ] RNN 대표를 R01으로 유지할지 R02로 바꿀지와 모델별 탐색 예산·선택 규칙 확인. 변경한다면 그림의 유닛 수·조건, 표의 파라미터·Accuracy·F1·SD, 본문 설명을 함께 갱신.
- [ ] 개발 validation 연구로 제출할지, 대상과 시점을 고정한 공식 test 평가를 추가할지 확정. 현재 원고 수치는 공식 test 결과가 아니다.
- [ ] 제목·주장·결론·참고문헌과 최종 제출본을 전원이 검토.
- [ ] 교수님 지도·AI 보조 사용 등의 표기는 실제 상황과 학회·수업 기준에 맞게 확인. 수행하지 않은 실험·오류·성능을 추가하지 않음.

## 이미 확인한 형식과 재검사 기준

- [x] 대학생 양식 사용, 원본 페이지·여백·글꼴·제목 및 저자란 보존.
- [x] 연구 배경·연구 내용·제한 조건·기대효과 및 활용·결론·참고 문헌 구성.
- [x] 본문 2단, 양쪽 정렬과 원본 본문 크기·들여쓰기·줄 간격.
- [x] 공통 구조 그림 1개·비교표 1개, 개체 ‘글자처럼 취급’.
- [x] 그림·표 제목은 휴먼명조 9 pt 중앙 정렬 일반 문단, 앞뒤 한 줄 공백.
- [x] 꼬리말 페이지 번호 없음, 예시 이름·학교·감사 문구·양식 작성 지침 제거.
- [x] 참고문헌까지 전체 2쪽. 실제 HWP 저장 후 다시 불러와 확인.
- [x] 두 쪽 시각 검토, 두 번째 쪽의 원본 문서와 정확한 본문 배치 좌표 대조.
- [x] MD와 HWP 본문 일치, 표 수치는 재계산한 CSV와 일치, 그림 바이트 보존.
- [ ] 미확정 정보를 채우거나 내용을 수정한 뒤 **다시 최대 2쪽인지 확인하고 두 쪽을 모두 검토**.
- [ ] 최종 HWP 파일로 온라인 제출하고 접수 결과 보관. 사용자에게 전달된 학회 안내는 PDF 대신 한글 파일 제출이다.

수업 발표 자료는 기존 커리큘럼 PPT·상세 개인 보고서를 사용한다. 이 2쪽 학술 원고와 목적·설명 깊이를 구분하되 같은 원자료에서 수치를 가져온다.
