# 그림 2 개정 기록 · v10.4

## 지적과 원인

v10.1의 F1 표시 범위는 0.98~1.00 부근이었고, v10.2·v10.3에서 0부터 시작하는 범위로 바뀌었다. 작은 점수 차이를 과장하지 않는 축이지만, 80 mm 지면에서는 평균과 오차막대가 모두 오른쪽에 겹쳤다. CPU 로그 축에도 실측 수치를 쓰지 않아 독자가 점의 위치만으로 값을 추정해야 했다. 결과적으로 성능과 비용을 함께 판단하는 그림의 목적이 약해졌다.

## 반영 내용

| 독자가 알아야 할 것 | 새 그림의 표현 |
| --- | --- |
| 각 모델의 실제 성능 | Macro F1 소수점 네 자리 직접 표기; NN 3 seed 평균·LR 단일 학습 명시 |
| 실제 처리 시간 | 0부터 시작하는 선형 막대와 ms 소수점 세 자리 수치 |
| 반복 실행의 시간 차이 | 실행별 중앙값의 최소~최대 가로선; 막대는 중앙값들의 중앙값 |
| 입력을 맞춘 비교 대상 | 동일 통계 특징 18개를 쓰는 LR3·FMLP3 두 행 강조 |
| 핵심 비용 차이 | FMLP3/LR3 = 1.04275/0.0734 ≈ 14.2배, 반올림 전 계산 |
| 측정 범위 | 직접 3상태, 같은 PC, batch 1, 전처리 포함을 그림 안에 명시 |

성능 SD는 표 1에 그대로 남겼다. 정확한 점수를 읽는 역할과 시간 차이를 보는 역할을 나누었다. 그림 1, 표 1, 저자, 사사, 연구 제목, 고정 실험 결과는 바뀌지 않았다. 그림 2의 캡션과 결과 해석 문단만 함께 정리했다.

## 이 그림에서 읽을 결론

직접 3상태의 모델별 대표 F1은 0.9905~0.9994이며 PC 처리 시간은 0.073~4.943 ms였다. 같은 입력 특징을 쓰는 LR3와 FMLP3도 측정된 처리 비용이 달랐다. 활동 요약이라는 출력 요구에 맞춰 성능과 구현 비용을 함께 검토할 근거다.

작은 F1 차이로 통계적 우월성·동등성을 주장하지 않는다. 나머지 네 모델은 시계열 입력을 사용하므로, 여섯 행의 차이를 구조 하나만의 인과 효과로 해석하지 않는다. CPU 시간은 해당 구현·라이브러리·하드웨어의 관측값이며 휴대전화에서 측정한 값이 아니다. 6종 행동 정보가 필요한 목적의 성능은 표 1에서 별도로 판단한다.
