## 1. 연구 배경

스마트폰 센서 기반 활동 기록은 필요한 행동 구분 수준에 따라 분류기의 요구가 달라진다. 기존 연구는 계층적 특징 선택[2]과 소수 특징의 선형 분류[3]를 제시했다. 본 연구는 6종 세부 행동과 3상태 요약을 구분하고, 예측 병합과 직접 학습을 대조한다. 같은 특징·목표의 분류기 비교와 사람 독립 test, CPU 실측을 결합하여 출력 요구에 따른 모델 선택 근거를 제시한다.

## 2. 연구 내용

2.1 데이터와 실험 조건

UCI HAR[1]의 허리 착용 스마트폰에서 신체·총 가속도와 각속도로 구성된 9채널(50Hz, 128시점, 50% 중첩)을 사용했다. 공식 train을 학습 16명·5,577구간과 검증 5명·1,775구간으로 나누고, 조건·모델 고정 후 test 9명·2,947구간을 평가했다. 사람·원 행 중복을 배제하고 원본 센서·라벨과 캐시를 대조했다. 표준화는 학습 통계를 사용했다. Macro F1은 각 목표 클래스의 F1 산술평균이다.

걷기·계단 오르기·내리기를 이동, 앉기·서기를 앉거나 서 있음, 눕기를 누워 있음으로 정의했다. 6종 argmax의 상태 병합과 3상태 직접 학습을 비교했다. 선형 로지스틱 회귀(LR3)와 특징 MLP(FMLP3, 18→128→64→3)는 같은 채널 평균·표준편차 18개, 특징 표준화 통계와 정답을 사용했다. LR은 L2, C=1, lbfgs로 한 번 학습했다.

시계열 MLP(128→64), CNN(64/128/128→64), RNN(32), LSTM(64→32)은 기존 6종 모델과 3출력 학습 조건을 사용했다. CNN의 Dropout은 0.3이다. NN은 Adam 0.001, batch 64, 최대 40 epoch, 검증 손실 patience 6·최선 복원, seed 2026~2028을 적용했다. 개발 비교 뒤 추가 NN 15회와 평가 구성을 고정하여 모든 seed의 test를 보고했다.

2.2 공식 test 결과

표 1. 공식 test Macro F1 (NN 평균±표본 SD)

| 모델 | 6종 | 6종→3 | 직접 3 |
| --- | --- | --- | --- |
| MLP | 0.8816 ±0.0164 | 0.9796 ±0.0031 | 0.9918 ±0.0024 |
| CNN | 0.9053 ±0.0136 | 0.9950 ±0.0027 | 0.9962 ±0.0028 |
| RNN | 0.7217 ±0.0669 | 0.9788 ±0.0076 | 0.9905 ±0.0027 |
| LSTM | 0.8767 ±0.0183 | 0.9866 ±0.0065 | 0.9959 ±0.0029 |
| LR | 0.7486 | 0.9865 | 0.9994 |
| FMLP | - | - | 0.9986 ±0.0002 |

6종 F1은 CNN 0.9053, LR6 0.7486이었다. 직접 3상태는 네 NN의 평균에서 병합보다 높았고 같은 seed 12쌍 중 11쌍에서 증가했다. LSTM seed 2027의 차이는 -0.0011이었다. 같은 특징의 LR3·FMLP3는 F1 0.9994·0.9986, 파라미터 57·10,883개였다. LR3의 2건 오류는 모두 사람 9의 앉기 구간을 이동으로 예측한 경우였다. NN은 세 seed 평균±표본 SD, LR은 단일 학습이다.

2.3 준비된 센서 구간의 처리 비용

동일 PC CPU·4스레드, batch 1에서 검증 첫 구간을 50회 워밍업 후 500회 반복 측정했다. 표준화·특징 계산·모델 호출·확률·클래스 반환을 포함한 중앙값은 LR3 0.073ms, FMLP3 1.043ms였다(그림 2). 각 실행 중앙값의 중앙값으로 집계했다. 수집·필터링·구간화·초기 로딩은 측정 범위 밖이다.

## 3. 평가 범위와 결과 해석

평가 대상은 허리 착용 6동작의 고정 사람 분할이고, 3상태 점수는 요약 과제의 성능이다. 같은 특징 대조는 LR3·FMLP3이며, 시계열 NN은 입력·학습 설정을 포함한 구성으로 비교한다. seed SD는 고정 test의 학습 변동이다. 시간은 NumPy·TensorFlow를 포함한 준비된 2.56초 구간의 PC 처리 비용이다.

## 4. 기대효과 및 활용

카메라·GPS 없이 센서 구간에 이동·앉거나 서 있음·누워 있음 태그를 부여하는 활동 요약 모듈의 구성 근거를 제공한다. 통계·선형 구성은 이 세 상태를 작은 분류기로 처리했다. 좌식 시간이나 계단 구분을 요구하는 기록은 앉기·서기와 이동 세부 라벨을 유지해 6종 지표로 선택한다. 적용 단위는 구간별 상태 태그이며 누워 있음은 자세 라벨이다.

## 5. 결론

공식 test에서 18개 통계 특징의 선형 모델은 57개 파라미터로 3상태 F1 0.9994와 PC 처리 0.073ms를 기록했다. 동일 특징 MLP의 F1 0.9986과 함께, 이 요약 과제에서 단순 구성의 높은 분류 성능을 확인했다. 본 연구는 출력 수준을 먼저 정하고, 같은 목표의 직접 학습·단순 기준선·처리 비용을 대조하여 활동 기록의 분류 구성을 선택하는 실험적 근거를 제시했다.
