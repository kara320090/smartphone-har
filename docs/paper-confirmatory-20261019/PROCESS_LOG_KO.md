## 개발 단계 완료 (공식 test 개봉 전)

- 추가 학습 15/15회 완료. 별도 프로세스에서 seed 3개씩 실행했고 학습 결과를 교체하지 않았다.
- 저장소 루트 재실행 결과 기존·신규 테스트 71개 모두 통과했다. 수집 실패는 실행 경로 차이였으며 모델 코드를 수정해 통과시킨 것이 아니다.
- 기존 모델 12개·새 모델 15개·선형 모델 2개, 총 29개 모두 전체 validation 1,775개에서 예측 클래스 일치 및 확률 rtol=1e-5, atol=1e-6을 통과했다.
- 29개 모델의 비용을 각각 새로운 프로세스에서 순차 측정했다. 학습과 동시 실행하지 않았다. 각 프로세스 50회 워밍업·500회 측정, 두 범위(준비된 입력 이후 / 센서 구간부터 출력까지)의 원시 기록과 메모리를 보존했다.
- 현재 환경은 Python 3.11.9, TensorFlow 2.21.0, Keras 3.15.1, NumPy 2.2.6, Intel Family 6 Model 183 CPU다. 기존 모델 학습 당시 Python·CPU와 다르므로 과거 시간 측정치를 재사용하지 않았다.
- 실제 학습 당시 소스 해시 2종(14회/1회)을 정확한 바이트로 보존했다. 경로 환경변수 추가 외 학습 함수는 동일하다. 최종 평가 소스에는 설정·드라이버·학습 소스 스냅샷을 lock에 포함하는 기능을 추가했다.

## 원고 편집과 검증

- 위 test 결과에서 표·그림·문단 숫자를 생성해 v10 HWP/PDF/MD를 작성했다. 편집은 평가 이후 이루어졌지만 동결한 평가 코드·모델에는 변경이 없다.
