# 투고 전 확인표

이 파일은 최종 확인 사항을 분명히 하기 위한 안내다. 현재 학회에 제출하지 않았다.

- [x] 첨부 대학생 양식을 기반으로 native HWP 파일 작성, 저장·재로딩 확인
- [x] 최대 2쪽, 원본 글꼴·여백·장 구성·2단 보존, 두 페이지 그림·표 배치 확인
- [x] 기준 네 구성 각 세 seed, 총 12회의 저장 예측에서 개발 지표 대조
- [x] 신규 분석 21,300행 검사 및 실행별·피험자별 지표 대조
- [x] 표·그림·본문 수치 일치, seed SD와 사후 분석 표기
- [x] 미평가 test·구성 차이·단일 사람 분할·원인 미측정의 한계 명시
- [x] 공개 데이터와 선행 연구 인용, 타인 결과·그림을 우리 산출물로 사용하지 않음
- [ ] 실제 저자 명단·순서, 학교·학과·이메일, 교신저자·지도교수 확인
- [ ] 전원이 고정 대표 구성(R01 포함)과 원고의 해석에 동의하는지 검토
- [ ] 데이터 담당자가 구간·채널·분할·표준화 설명 최종 검토
- [ ] 교수님과 팀이 개발 분석으로 제출할지, 공식 test 평가를 추가할지 결정
- [ ] 최종 편집 후 HWP의 페이지 수·본문과 표·그림 수치 다시 대조
- [ ] 학회 온라인 투고 절차에 따라 최종 확정 HWP 제출

[공식 추계 안내](https://dcs.or.kr/homepage/custom/submit) · [일반/대학생 양식 공지](https://dcs.or.kr/board/forms/article/284050)

현재 파일에는 ‘확인 필요’ 저자 정보가 있으므로 그대로 최종 투고하지 않는다. 페이지 초과에 대한 이번 추계의 예외 승인은 확인하지 않았다.
