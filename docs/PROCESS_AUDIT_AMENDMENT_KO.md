# 초기 가중치 대조 실험 추가 계획

2026년 9월 29일 한국 시간, 초기값 검사에서 E02와 E08의 첫 Dense 층은 같지만 둘째 층과 출력층은 동일 seed에서도 달라짐을 확인했다. 근거는 reports/process_audit/initialization_control.json이다.

이 문서는 해당 발견 이후, 아래 추가 학습 결과를 보기 전에 작성했다. 기존 7조건 × 3seed 계획은 유지하고 추가 대조 실험을 별도로 보고한다.

- 이름: E08W. E08과 동일한 Dropout 0.3 구조에 E02의 모든 Dense 초기 가중치·편향을 층 이름으로 복사한다.
- seed: 2026, 2027, 2028. 기존 E02와 같은 검증 사람, 전처리, Adam, 학습률, 배치, 조기 종료 규칙을 사용한다.
- 총 3회 수행하며 초기값의 배열 완전 일치와 SHA-256을 실행별로 기록한다.
- 기존 E08과 E08W, 기준 E02의 Macro F1을 seed별로 비교한다.
- 이 실험도 Dropout 마스크와 학습 경로·조기 종료 결과는 달라진다. 초기값 차이라는 혼동 요인 하나를 제거하는 대조이며, Dropout의 보편적 효과나 최적 비율을 증명하지 않는다.
- 전체 후속 평가를 미리 설계한 것처럼 서술하지 않고, 코드 검사 결과에 따라 추가한 대조 실험으로 표시한다.
