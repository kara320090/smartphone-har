# DCS 2026 대학생 공동 논문 개정 v4

2026-10-14 · **스마트폰 행동 인식 신경망의 성능·규모 절충과 피험자별 편차 분석**

하계 관련 논문 5편과 HAR 선행 연구를 검토해 기존 12회 기준 실험의 연구 배경·방법·결과 해석·활용·결론을 다시 작성했다. 새 학습이나 공식 test 평가는 없으며 대표 구성 M01·C01·R01·L01과 결과 수치를 유지했다. 모델 규모와 평균 성능의 절충, 행동군 평균 순위 변화와 공통 취약 피험자를 연결한다. v4에서는 전체 5명 결과를 유지한 채 검증 피험자 한 명씩을 제외하는 다섯 사후 진단을 추가하고, 집단 구성에 따른 평균 순위 변화를 설명한다. 재학습·모델 선택 변경·LOSO 교차검증을 수행한 것은 아니다.

저자 순서는 **이봉헌·유재윤·정회서·한윤섭·최승빈**, 제1저자·발표자는 이봉헌, 지도교수는 황세웅이다. 소속·학생 이메일은 제공된 응용프로젝트 프로필의 각 이름과 연결해 반영했다. 교수님을 공동저자 또는 교신저자로 자동 추가하지 않았다.

사사 적용 여부·최종 문구, 교신저자, 최종 투고 내용은 아직 확인할 항목이다. 공개 HWP·PDF·MD에는 **지원 사실을 확정하는 사사를 넣지 않았다**. 학교 지원 서류·학번·전화번호·개인정보 동의서·과거 타인 원고·논문집 전문은 이 공개 묶음에 포함하지 않는다. 로컬 사사 확인용 파일과 구분한다.

## 결과와 해석의 범위

- 학습 16명·5,577구간, 개발 검증 5명·1,775구간. 검증은 epoch 선택에도 사용했다.
- 표의 SD는 같은 사람 분할의 seed 2026·2027·2028 표본 SD이며 사용자 모집단 신뢰구간이 아니다.
- CNN과 LSTM의 평균 Macro F1 차이는 0.0076, LSTM 파라미터는 75.2% 적다. 동등성·모바일 속도·전력은 입증하지 않았다.
- 행동·피험자별 분석은 저장 예측의 사후 분석이다. 오류 원인·순수 구조 효과·새로운 최고 성능을 주장하지 않는다.
- 다른 논문과 지표·데이터·분할이 달라 점수로 직접 비교하지 않는다. 참고 사례의 수상 여부나 공식 심사 배점은 확인되지 않았다.

비교표는 `reports/team_comparison/baseline_summary.csv`, 그림·본문 분석은 `reports/team_error_analysis/`에서 가져왔다. 지표 재계산 코드와 그림 생성 코드는 `tools/analyze_team_errors.py`, `tools/make_team_error_figure.py`다. [앞선 v3](../dcs-team-paper-research-v3/README.md)와 기존 보고서·수업 PPT는 수행 기록으로 보존한다. 이 원고는 제출·채택·수상을 완료한 자료가 아니다.

새 분석의 재현 코드는 `tools/analyze_subject_composition.py`, 추가 그림은 `tools/make_subject_composition_figure.py`다. LSTM 예측은 기존 LSTM Release의 실행 폴더를 준비한다. 분석은 test 배열을 로딩하지 않으며 기존 대표 결과를 교체하지 않는다.
